# Learning Sliding Ferroelectricity

A learning-oriented literature map that connects:

**statistical physics → disorder / RFIM → depinning → domain-wall physics → sliding ferroelectricity**

The site is intentionally static and dependency-free so it can be hosted directly on GitHub Pages.

## What the V0.1 prototype includes

- interactive literature dependency graph
- category and route filters
- paper learning cards: why to read, concepts, prerequisites, next papers
- a 10-paper core route
- local reading-progress tracking via `localStorage`
- direct links to DOI / arXiv / publisher pages

## Deployment

GitHub Pages is deployed by `.github/workflows/pages.yml` from the `main` branch.

Expected URL:

`https://leonakaka.github.io/learning-sliding-ferroelectricity/`
