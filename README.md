# Learning Sliding Ferroelectricity

Literature-driven personal learning site for sliding ferroelectricity, domain-wall switching, pinning, creep, depinning, disorder, RFIM, and numerical modeling.

## Learning contract

This is not a paper bookmark list. Each deep lesson is organized around:

**paper source text → original paper Figure → Chinese explanation → what the authors actually established → what they did not establish → why the next paper follows**

Original paper wording is kept as selectable HTML text, not paragraph screenshots. Scientific Figures are frozen local assets derived from the project literature PDFs; deployment does not redownload papers or regenerate crops.

## Eight-module V1

1. What is Sliding Ferroelectricity?
2. Switching Pathways
3. Domain Walls
4. Pinning & Creep
5. Depinning
6. Disorder & RFIM
7. Numerical Modeling
8. Current Frontiers

The site is intentionally static and reading-first. The final GitHub Pages workflow only validates the frozen evidence chain and publishes it; obsolete evidence-regeneration scripts that could recreate paragraph screenshots are not part of V1.
