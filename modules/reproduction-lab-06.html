Learning Sliding Ferroelectricity / Reproduction Lab / Lesson 06

模型降维已经对上，不代表 \(\zeta=2/3\) 已经有资格宣布

Caballero 2020 Fig.5 是这篇论文最接近你后续 Paper2 的一张图：同一个 random-bond problem，同时跑 2D Ginzburg–Landau bulk 和映射后的 1D Edwards–Wilkinson line，再用 real-space roughness B(r,t) 与 Fourier-space structure factor S(q,t) 检查两种描述是否一致。更重要的是，这一课第一次把“模型映射是否正确”和“是否已经进入渐近普适区”严格拆成两个不同问题。

本课判据：GL↔EW 必须在 B(r) 和 S(q) 两个 observable 上同时接近，才能叫 cross-model geometry mapping pass；而要声称 random-bond \(\zeta=2/3\)，还必须要求 B-derived 与 S-derived effective exponent 在同一受控尺度窗内彼此兼容。前者通过，不自动推出后者。

0 · 原论文 Fig.5 vs 我们的 t=1000 checkpoint

结论先写在前面：我们的 GL 与 EW geometry 已经明显互相跟随；但当前小系统/有限时间下，B-derived 和 S-derived ζ 还没有闭合，所以这一步只能写 cross-model mapping pass，不能写“已复现 random-bond universality”。

1 · 论文真正测试的是两层命题

命题 A · model reduction

给定同一 bulk disorder physics，2D GL 提取出的 wall 和映射后的 1D EW 是否产生相同几何统计？这主要由 B(r) 与 S(q) 的 cross-model agreement 检验。

命题 B · asymptotic scaling

系统是否已经进入足够大的尺度/足够长的时间，使 roughness exponent 接近 random-bond equilibrium value ζ=2/3？这需要 estimator consistency 与 size/time convergence。

最常见的逻辑跳跃：看到 S(q) 的斜率接近 2/3，就直接说 universality 成立。但如果同一份 interface 的 B(r) 还给出明显不同的 effective ζ，这最多说明“某个 Fourier window 看起来接近目标”，不是闭合证据。

3 · 2D GL 与 1D EW 现在共享同一条 disorder lineage

2D bulk 继续使用 Lesson05 的 random-bond coupling：

Vζ(φ)=V(φ)[1+εζ(x,y)]

1D EW 不再随便造一个“看起来有点相关”的 random force，而是使用 Lesson05 已经验证的 wall-level pinning statistics：

η̃∂tu = c∂²yu + Fp(u,y) + ξ̃
这就是复现梯子的意义：Lesson03 已锁死 EW thermal dynamics；Lesson04 已锁死 finite-T bulk→wall estimator；Lesson05 已锁死 bulk RB→pinning correlator。Lesson06 如果出问题，我们已经不需要从“是不是 Laplacian 写反了”重新怀疑，而能把诊断集中到 disordered dynamics、finite size/time 或 mapping assumptions。

4 · 第一关：B(r) 的 cross-model geometry

B(r)=⟨[u(y+r)−u(y)]²⟩

在预先声明的 4≤r≤32 窗口中，我们用 symmetric relative difference 比较 GL 与 EW，而不是拿其中一个当“真值”。CI 保存的最终结果：

B median relative difference = 1.227%
这已经是非常强的 cross-model agreement。它说明在这个 checkpoint 上，bulk GL 与 reduced EW 对 real-space wall geometry 的描述是相容的。

5 · 第二关：S(q) 必须独立跟上

S(q)=⟨|uq|²/L⟩

Fourier space 对 small-scale / large-scale crossover 的权重和 B(r) 不同，因此它不是“重复画一遍 B”。我们先对 q 做预定义 log bins，只用 bin center 比较两模型，避免高 q 密集 modes 机械支配误差：

S(q) log-bin median relative difference = 6.122%
仍在事先设定的 10% gate 内，所以 cross-model mapping 在 Fourier observable 上也通过。
log bins 不是新的 n。 它只是让跨数量级的 q 区域获得更均衡的 estimator weight；统计独立单位仍然是 realization，不是 Fourier modes，也不是 bins。

6 · 然后才看 exponent：这里故意不“挑漂亮答案”

estimator2D GL1D EWpaper asymptotic guide
ζ from B(r)0.5389060.509213ζRB=2/3≈0.6667
ζ from S(q)0.6943080.664796

如果只看 S(q)，你很容易说“EW=0.665，几乎就是 2/3，复现成功”。但同一时刻 B(r) 仍只有约 0.51–0.54。这说明当前系统仍有明显 crossover / finite-size / finite-time structure，不能把一条 estimator 的接近当作渐近 universality。

ASYMPTOTIC ζ GATE NOT PASSED。 当前正确写法是：GL 与 EW 在同一 observable 上高度一致，说明 model reduction 已有强证据；但 B-derived 与 S-derived exponent 尚未在同一 scaling regime 中闭合，因此 ζ=2/3 只能作为 paper target / slope guide，不能升级成我们的 measured asymptotic exponent。

7 · 为什么这个“没通过”反而很有教学价值？

排除代码基础错误

B 和 S 的 GL↔EW agreement 已很好，说明两套模型的 geometry pipeline 不是各跑各的。

暴露 crossover

同一模型的 B 与 S 给不同 effective ζ，直接告诉你目前 fit window 不处在单一 asymptotic regime。

决定算力投向

下一步应优先做 cheaper EW 的 time/size ladder，确认 exponent convergence 后再决定是否值得把 2D GL 也扩大。

8 · 另一个 sanity check：bulk wall profile 还健康吗？

如果 disorder 已把 wall 撕成 bubbles / multiple-valued geometry，即使 B 与 S 看起来还能算，single-line mapping 也可能失去物理意义。本课的 finite-T soliton fit 给出：

mean fitted amplitude A0.982981
mean fitted width w1.371256
mean profile-fit RMSE0.077925

A 与 w 仍接近 clean low-T profile（A≈1、w≈√2），因此当前 checkpoint 还在一个可合理约化成 interface 的 regime。以后 disorder 更强时，这一层 topology/profile QC 必须先于 ζ fit。

10 · 下一课：先用便宜的 EW 做 time/size ladder

如果我们现在直接把 2D GL 从 64×128 推到论文的 256×4096 并跑到 10⁶，只是在用算力掩盖诊断不清。更合理的是先在便宜很多的 1D EW 上做：

L: 128 → 256 → 512 → 1024　；　t: 10³ → 10⁴ → 10⁵

看 ζB 与 ζS 是否朝同一个 plateau 收敛。只有这一层成立，才值得把对应的 selected checkpoint 回填到 2D GL。这个策略正是为了解决“经典论文很耗算力，学习者跑不出来就无法判断正确性”的问题。

再往你的 sliding-FE 项目迁移：以后测 ζ 时，不会因为某一个 S(q) window 给出漂亮值就宣布 universality。先要求 wall mapping / topology 合法，再要求 B 与 S 在同一 scale story 下兼容，最后才看 size/time convergence。这就是你 Paper2 roughness gate 的代码版来源。
