第一次真正复现论文曲线：thermal roughness 为什么从 0 长出来？

前两课都还是 gold test：先验证 wall profile，再验证 wall extractor。现在第一次进入 Caballero 2020 的定量主结果。论文 Fig.2 从完全平的 interface 出发，让 thermal noise 逐步建立几何相关，并把数值 B(r,t) 与解析 Eq. (19) 直接比较。我们先只复现其中最干净的 1D Edwards–Wilkinson 层，因为这里既有论文 Figure，也有 exact analytic benchmark。

本课验收标准升级：不是“曲线趋势一样”，而是 paper protocol → analytic Eq.19 → our simulation 三层对照。我们预先冻结比较窗口 4≤r≤64，再看 relative error；不能看完结果后再挑一段最像的。

2 · Eq. (15)：这次第一次真的加 thermal noise

η̃ ∂tu = c ∂²yu + ξ̃(y,t)
⟨ξ̃(y,t) ξ̃(y′,t′)⟩ = 2 η̃ T δ(y−y′) δ(t−t′)

论文通过 bulk-to-line projection 得到这条 EW equation。α=δ=γ=η=1 时，Eq. (16) 给出 η̃=c=2√2/3，因此 diffusion ratio c/η̃=1。离散到 dy、dt 后，每一步直接加到 u 的 thermal increment 是：

Δuth = √[2TΔt/(η̃ dy)] · N(0,1)
这和你的 2D quenched disorder 缩放不是一回事。 thermal white noise 同时是 spatial + temporal delta correlation，所以离散振幅同时依赖 cell size 和 dt；quenched RF 只在空间上随机、时间上冻结。

3 · Eq. (19)：为什么这篇特别适合拿来学代码？

因为它不仅给模型，还给了 flat initial condition 下 B(r,t) 的解析答案。令：

z = √[η̃/(8ct)]
B(r,t)=Tr/c · [1 − erf(zr) − {exp[−(zr)²]−1}/(√π zr)]

而长时间极限进一步变成：

Bth(r)=Tr/c

所以这一课至少有两道独立标尺：完整 Eq.19 检查 finite-time crossover，Tr/c 检查 late-time short-scale thermal regime。

4 · 从连续 Langevin 到 6 行 Euler

真正的 EW 更新
lap = (np.roll(u,-1,axis=1)
       - 2*u
       + np.roll(u,1,axis=1)) / dy**2

u += dt * (c/eta_tilde) * lap
u += np.sqrt(2*T*dt/(eta_tilde*dy)) * rng.standard_normal(u.shape)

这里每一行都有可核验含义：periodic Laplacian 对应 line elasticity；第二行是 deterministic relaxation；第三行来自论文 Eq. (14–15) 的 FDT noise。没有额外“调出来的”噪声幅度。

5 · B(r,t) 不是拿一条 interface 就结束

B(r,t)=⟨[u(y+r,t)−u(y,t)]²⟩

本课括号里同时平均 y 和 independent thermal realizations。论文 Fig.2 左列展示 10 条 realization 的离散程度，中列再画平均值。我们为了快速降低 Monte Carlo noise 用 64 realizations，但最终 statistical unit 仍然是 realization，不是 r-bins。

r=1…64 的 64 个点不是 n=64 个独立实验。 它们来自同一批 interfaces，只是同一个 correlation function 的不同 separation。
