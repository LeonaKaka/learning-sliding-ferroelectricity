首页 / What is Sliding Ferroelectricity?

一层没变，为什么叠起来以后会有极化？

Sliding ferroelectricity 最容易被一句“层间滑动翻转极化”说得太快。第一遍真正需要搞清的是四步：堆垛改变局域对称性 → 层间电荷重新分布 → 产生面外偶极 → 相对平移把一种 polar stacking 变成另一种。

这一页只回答三个基础问题：AB 与 BA 为什么不是同一个状态？为什么它们的面外极化方向相反？“sliding”究竟是在改变极化本身，还是在改变产生极化的 stacking registry？

1. 先把“sliding”翻译成人话：改变的是两层原子的相对注册关系

Wu 与 Li 的 2021 Perspective 很适合作为第一入口，因为它没有把 sliding FE 当成一个材料名，而是先给出机制语言。重点不是“层能不能滑”，而是两层在 AB、BA 等 registry 中，哪些原子上下对齐、哪些落在六元环中心，这种相对位置如何改变界面电荷分布。

原文段落 · Wu & Li 2021PNAS · Theoretical Model · PDF p.2
这一段的逻辑是连续的

作者先从“两个层并不等价”讲起：不等价带来净层间电荷转移，非中心对称的 AB 配位因此支持面外极化；随后才指出，AB 与反向极化状态之间相差一个面内平移，所以极化翻转可以表述成相对层间 translation。这里的主语一直是 stacking registry，不是一整块晶体凭空被面外电场横向推走。

先只看 A

上下两层的化学组成没变，改变的只是横向 registry。红色极化箭头却反向，说明 order parameter 的符号与相对堆垛绑定。

再看势垒曲线

它告诉你两种 registry 之间存在一条低能量路径；但“有低势垒路径”与“真实器件里一定以整体 coherent sliding 切换”不是同一个结论。后者要等到 switching/pathway 与 DW 章节再判断。

2. Yasuda 2021：AB / BA 的相反极化不只是计算图里的箭头

Yasuda 等人把一个原本非铁电的 hBN 单层，通过平行堆垛组合成 polar bilayer。这个实验最重要的不是“又发现一种二维铁电”，而是把 stacking order ↔ polarization sign 变成可测的关系。

原文段落 · Yasuda et al. 2021Science 372, 1458 · Abstract
这里有两个层次不要混

第一层是结构：parallel-stacked bilayer BN 因 stacking 形成面外极化，而且极化方向随 stacking order 反转。第二层才是器件读出：他们借助邻接 graphene 的电阻响应追踪 polarization switching。结构机制与读出手段是两件事。

A 为什么不 polar

AA′ 是 180° 旋转后的自然 bulk stacking，会恢复整体反演对称性。没有一个唯一的 z 方向被选出来。

B/C 为什么互为 ±P

AB 与 BA 交换了哪一种原子位于另一层原子正上方，局域轨道与电荷重分布随之反转。图中蓝色 charge-lobe 示意和红色 ±P 箭头就是作者给出的物理图像。

E/F 真正告诉什么

重构后的相邻三角区域呈现不同 PFM contrast，并由 DW 分隔。这支持“不同 stacking domain 对应不同 polar state”，但 PFM contrast 本身不是一张直接的原子尺度电荷密度图。

3. Vizner Stern 2021：把 AB / BA 从结构示意变成真实空间中的两种 domain

同年另一篇 Science 从不同角度补上证据链：不是只看一条器件 hysteresis，而是在真实空间里看到交替的表面势 domain，再把这些区域与 AB / BA interfacial stacking 对上。

原文段落 · Vizner Stern et al. 2021Science 372, 1462 · Abstract
这篇和 Yasuda 不是重复

它强调的是空间图像：相邻 domain 的 normal polarization 相反，而两个 domain 之间只差一个 lattice-site lateral shift；biased tip 又可以把 polarization switching 与 lateral sliding 绑在同一个实验叙事里。

黑白不是“两个材料”

它们是同一 bilayer interface 的两种 registry。局域电势反差来自相反的界面极化。

为什么还要 DFT / model

KPFM直接测的是表面电势，而不是把 polarization vector 本身拍出来。作者把测得的 ΔV、尺寸依赖和计算的 interfacial polarization 合起来，才把黑/白 domain 解释为 AB / BA 的相反极化。

4. 到了 3R-MoS₂，多一层就多一个界面：于是“极化”不再只有 +P / −P

bilayer 只有一个 vdW interface，所以最自然的是两种反向 interfacial dipole。trilayer 有两个 interface，它们可以同向，也可以反向；总极化于是可以出现中间值。Meng 2022 把 layer number 本身变成了一个控制维度。

原文段落 · Meng et al. 2022Nature Communications 13, 7696 · Abstract
“multiple states”不是凭空多出几个 P 值

作者明确把异常 intermediate polarization states 与 multilayer 3R-MoS₂、layer number 和 interlayer dipole coupling 联系起来。换句话说，总 P 是多个界面偶极组合后的结果；每个 interface 的 stacking 是否翻转，会改变这个组合。

2L

只有 1 个 interface dipole：最简化的状态空间就是 ↑ 或 ↓。

3L

有 2 个 interface dipole：↑↑、↑↓、↓↑、↓↓ 都可能成为结构上可区分的组合，因此出现中间净极化并不奇怪。

真正重要的后果

从这一刻开始，“switching”就必须问路径：先翻哪个 interface？两个 interface 会不会同时动？中间态能停多久？这正是下一章 Switching Pathways 的问题。

Ji et al. 2023 放在这里读最合适

前面四篇先建立直觉；再读 General Theory for Bilayer Stacking Ferroelectricity，用 layer symmetry / stacking operation 把“哪些 bilayer 能 polar”形式化。第一次学习不需要先把群论放在最前面，否则容易知道判据却没建立物理图像。

5. 学完这一页，应该把下面四句话说清楚

现在可以比较稳地说

特定相对堆垛会破坏整体反演对称性并伴随层间电荷重分布；AB / BA 可以对应相反面外极化；相对 lateral translation 改变 registry，从而把一种 polar stacking 变成另一种；多层体系因为拥有多个 vdW interface，可以出现组合式 intermediate polarization states。

这一页还没有回答

外加电场在真实器件中究竟怎样启动 lateral motion；switching 是整层 coherent sliding、局域 nucleation，还是已有 domain wall propagation；实验里的 coercive field 到底对应哪一个 microscopic barrier。这些不能从“AB ↔ BA 有低势垒”直接推出。
