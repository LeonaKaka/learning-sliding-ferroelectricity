Paper2-orientedT = 0isolated elastic wall

先把 fc 找对，再谈 v(f)、β 和 universality

从这一课开始，方法链正式离开 Paper1 的 RF/RB switching comparison，进入 Paper2 的 isolated-wall depinning。第一件事不是拟合 β，而是回答一个更基础的问题：对一个固定 quenched-disorder sample，怎样有证据地说“这里是 pinned，那边是 moving”，并把 sample-dependent threshold 锁进一个可复查的 bracket？

本课唯一权限：建立 threshold-search contract。没有 steady-state velocity fit，没有 β，没有把 hysteresis coercive field 叫成 depinning Ec。

0 · Ferrero / Rosso / Krauth 真正把什么叫作 depinning threshold？

权威文献使用 driven quenched Edwards–Wilkinson（QEW）形式：

γ ∂tu(x,t) = c ∂²xu + Fp(u,x) + f + η

在 T=0 的有限 disorder sample 中，Ferrero et al. Sec. 4.3.1 把 fcsample 定义为仍存在 metastable configuration 的最大 drive。原文最关键的一句只有：

“the maximal force for which a metastable configuration still exists”

Middleton 的 no-passing / forward-motion properties 使有限样本中的 pinned ↔ moving 分界具有明确意义。论文进一步强调：高精度工作可以通过“是否存在 metastable state”来找临界力，而不必依赖普通时间积分。

因此本课也要分清 authority：Ferrero 的 exact metastable-state algorithm 是更高层的 threshold authority；我们的第一版先用 direct relaxation 建立可解析 gold test、bracket 和 dt-invariance。它是进入 velocity measurement 前的 validation checkpoint，不是冒充 exact algorithm。

1 · 原论文 Figure 4：最终目标不只是一个数

不要比较数值大小。 Ferrero Fig.4 的 fc≈1.916 属于他们指定的 disorder normalization、system geometry 与 exact algorithm。我们的 0.7777 是另一套 pedagogical disorder realization 的 sample-specific threshold；它不是“复现 1.916 失败”，也不能拿来和材料的电场直接对应。

2 · 第一层：解析 saddle-node gold test

任何 threshold classifier 第一次出现，都先交给一个答案已知的问题：

du/dt = f − sin u　→　fc = 1 exactly

当 f<1 时存在固定点；当 f>1 时不存在固定点并持续前进。我们对同一个 pinned/moving 判据做二分，而不是给算法偷偷塞 fc=1。

3 · 第二层：一个真的 quenched elastic line

我们离散一条长度 L=32 的 elastic line，周期边界：

dui/dt = c(ui+1+ui−1−2ui) + Fp,i(ui) + f

每个 site 的 random potential Ui(u) 由独立 Gaussian field 经短程 Gaussian filter 得到，再取 Fp=−∂uU。因此这里是一个 smooth random-bond-like test landscape；u 方向的大周期只是为了有限存储，不把它宣称成 Ferrero 原代码的 disorder generator。

Pinned certificate

所有局部 force-balance residual 收敛到固定 tolerance，并连续保持。

Moving certificate

在同一 periodic disorder box 中，center of mass 前进两个完整 u-period，避免把长 transient 误叫 moving。

Bisection

永远保留 last-pinned / first-moving 两侧；报告 bracket，而不是假装一个无限精确的单点。

5 · 为什么“最后 pinned / first moving”比一个 fc 数字重要？

后面做 v(f) 时，如果直接把 threshold 当固定常数写死，会把 threshold uncertainty 偷偷转移给 β。更安全的流程是：

disorder sample → [f−, f+] → choose Δf relative to bracket → measure steady v → propagate threshold uncertainty

这也解释了为什么 coercive field 和 depinning threshold 不能混在一起：前者来自完整 switching / hysteresis protocol，可能包含 nucleation、多墙与 protocol-rate effects；这里的 fc 属于一条预先存在的 elastic wall 在 constant drive 下的 pinned↔moving transition。

6 · 这节证明了什么？没证明什么？

已经证明

threshold classifier 能恢复 exact 1DOF threshold；固定 quenched sample 上 pinned/moving bracket 可收缩到 1.5×10⁻⁴；结果对 dt=0.1→0.025 稳定。

还没证明

没有实现 Ferrero exact metastable-state algorithm；没有 thermodynamic fc；没有 finite-size scaling；没有 β、ζ、ν；也没有 sliding-FE 的 Ec。

对你的 Paper2：这节迁移时，变量 f 换成 constant electric drive E，对象换成 isolated pre-existing sliding-FE wall；但“解析/可控 benchmark → pinned/moving authority → bracket → dt/size check”这条 measurement contract 不变。
