从 φ(r,t) 到一条会 depin 的畴壁，中间到底做了哪些近似？

前两章已经把问题拆成两种语言：bulk order parameter 可以产生复杂畴结构，elastic interface 则擅长描述 threshold、roughness 和 universality。数值建模真正困难的地方，不是“把 TDGL 写进代码”，而是知道每一步 coarse-graining 保留了什么、丢掉了什么，以及网格有没有悄悄改掉你的物理参数。

学完这一章必须能回答：phase-field 的 order parameter 与 free-energy terms 各自代表什么；diffuse wall 怎样变成 emergent interface；random-bond / random-field 在连续场里怎样加入；为什么固定代码里的 σ 却改变 dx 会改变物理 disorder strength？

核心来源：Chen 2008 来自项目 Drive 根目录；Caballero et al. 2020 来自项目 Drive `03 Depinning, elastic-interface, RFIM theory`；Fedeli et al. 2019 来自项目 Drive 的 phase-field 文献集。Figure 均来自这些 PDF 本身。

1 · Chen 2008：phase field 不是画畴图的软件，而是一套自由能 + 动力学

最先要固定的是模型层级。phase-field 不追踪每个原子，而用空间连续的极化场 P(r) 描述局域状态；domain wall 不是单独画进去的几何线，而是 P 从一个自由能极小值连续过渡到另一个极小值的区域。自由能里至少要知道哪些项在竞争：local Landau potential 决定偏好的极化态，gradient term 惩罚过快的空间变化，electrostatic / elastic terms 则提供长程耦合与边界条件。

原文 · Long-Qing Chen 2008　J. Am. Ceram. Soc. 91, 1835–1844 · Drive PDF

It describes a domain structure using the spatial distribution of spontaneous polarization. The evolution of a domain structure towards equilibrium is driven by the reduction in the total-free energy of an inhomogeneous domain structure including the chemical driving force, domain wall energy, electrostatic energy as well as elastic energy.

With all the important energetic contributions to the total-free energy, the temporal evolution of the polarization vector field, and thus the domain structure, is then described by the time-dependent Ginzburg-Landau (TDGL) equations.

这里最重要的不是记某套 PbTiO₃ 系数，而是模型结构：state = field；physics = free-energy functional；dynamics = gradient descent / TDGL。
∂Pi(x,t)/∂t = −L · δF / δPi(x,t)Chen Eq. (44) 的核心形式。L 是动力学系数；F 里包含 local、gradient、electrostatic、elastic 等贡献。
为什么这里不再放 Chen Fig. 6：项目 PDF 中该图的内嵌 raster 本身只有 396×86；继续放大只会制造伪清晰度。这里保留作者原文与 TDGL 方程，把视觉证据留给后面原始分辨率更高的 Caballero Figure。

作者真正支持什么

phase-field 用空间分布的 polarization 表示 domain structure，并通过总自由能下降描述其演化；该框架能显式容纳 domain-wall、elastic 与 electrostatic 能量。

不要偷换成什么

Chen 的综述不意味着任意简化的标量 φ⁴ 模型都能定量代表某个 sliding-FE 材料。材料级预测需要重新说明 order parameter、symmetry、long-range terms 与参数来源。

2 · 把复杂铁电压成最小标量模型：你到底删掉了什么？

如果目标不是重现实验材料的全部畴结构，而是研究一堵 180° 壁在 quenched disorder 中怎样运动，可以进一步缩成一个标量 order parameter φ。最小自由能可以写成：

F[φ] = ∫d²r [ V(φ) + κ/2 |∇φ|² − (E + h(r))φ + … ]双井 V(φ) 给出 ±φ₀；κ 控制 diffuse-wall cost；E 是均匀驱动；h(r) 是一种可选的 local bias。省略号必须由你主动说明，而不是默认“都不重要”。

保留下来的自由度

局域 order parameter、有限壁宽、畴的生成/消失、曲率、overhang、bubble，以及在需要时加入长程场或多分量耦合的可能性。

被扔掉的自由度

具体原子滑移坐标、晶格级 Peierls potential、真实多层 stacking labels、完整 tensor polarization，以及若未显式加入就不存在的 electrostatic / elastic nonlocality。

建模纪律：“能产生一堵墙”不等于“已经是 sliding ferroelectric”。标量 TDGL 更适合回答 universality / disorder / interface dynamics；若结论依赖 3R stacking、shear coordinate 或层间电荷重排，就必须回到更贴近材料的自由度。

3 · Caballero 2020：什么时候 φ(x,y) 真能约化成 u(y)？

这篇就是 06 → 07 的关键桥。bulk GL 不对 interface 形状做先验假设；elastic-line 模型则把墙压成单值函数 u(y,t)。作者做的不是“说它们差不多”，而是从 GL 的 soliton profile 出发，把 wall position 当 collective coordinate，并比较两种模型的 roughness 与 structure factor。

原文 · Caballero et al. 2020　arXiv:2006.15130 · Drive PDF

For a bulk description, we consider a two-dimensional Ginzburg–Landau model evolving with a Langevin equation, and boundary conditions imposing the formation of a rectilinear domain wall. At this level of description no assumptions need to be done over the interface.

On a different level of description, we consider a one-dimensional elastic line model evolving according to the Edwards–Wilkinson equation, which only allows one to study continuous and univalued interfaces.

“only allows continuous and univalued interfaces” 正是上一章 overhang / bubble 警告的数学版本：一旦 wall 不能写成 u(y)，elastic-line observables 就需要重新定义。
φ*(x) = −φ₀ tanh(x/w),　w = √(2γ/α)Caballero Eq. (7–8) 的 soliton profile 与 wall width。只有当 wall profile 与几何假设受控时，把 bulk field 投影到 u(y,t) 才有物理意义。

真正能拿来用的判据

壁宽相对观察尺度足够小、interface 大体 single-valued、低温/弱 bulk fluctuation，并且抽出的 u(y) 的 roughness / structure factor 与 reduced model 在目标尺度上相容。

失效信号

强 nucleation、islands、persistent overhangs/bubbles、壁宽与相关长度同阶、强局域变形，或不同 wall-extraction 方法给出显著不同 ζ。此时不要强行拟合 elastic-line exponent。

4 · Dai 2026：什么时候单一 u(y) 不是“近似得粗”，而是自由度真的少了？

Caballero 的约化问题默认只有一堵主要 interface。multilayer sliding FE 会出现更直接的失效模式：不是 wall 变得有一点 overhang，而是体系本来就有多个 sliding interfaces。Dai 2026 的 trilayer γ-InSe 计算显示，相邻层的 DW 位于不同位置，中间可以形成 nonpolar domain，外场下又出现 staged motion 与显著 inter-DW interaction。

u(y,t)　→　{u1(y,t), u2(y,t), …}若多个 interface 的相对位移会改变能量和动力学，就还需要 interaction term，例如 Fint[u1−u2]；这只是 coarse-grained 结构示意，不是 Dai 论文直接给出的 Hamiltonian。

仍可做 single-wall minimal problem

当研究问题明确限定在 bilayer-like、一堵预存 wall、其它界面自由度被冻结时，单一 u(y) 仍是最干净的 universality test。

不能无条件外推

trilayer/multilayer 的 intermediate states、coupled DWs 与 inter-DW interaction 可能引入新的长度和时间尺度；单壁 β/ζ/ν 不能自动描述整个 multilayer switching。

模型边界不是缺点。真正严谨的说法是：先用 single-wall problem 测试最小 driven-interface framework；如果未来扩到 multilayer，就显式增加 interface index，而不是把所有额外自由度藏进一个更大的“noise”。

4.5 · Nondimensionalization & identifiability：参数多，不等于信息多

一套 continuum model 可以同时写 κ、V0、P0、Γ、disorder amplitude、correlation length 和 temperature；但一条实验曲线通常不能把它们全部独立决定。真正应该先问的是：某个 observable 约束的是哪个参数，还是只约束某个参数组合？ 如果这个问题没回答，所谓“参数拟合得很好”可能只是 non-identifiability。

最重要的校准顺序：先定自由度与 symmetry → 再定 clean statics → 再定 clean dynamics → 再加 disorder → 最后才拿没参与校准的 observable 做验证。

4.5.1 · 先用 clean single-harmonic sector 看清“参数组合”

对 Research Track 里采用的 periodic stacking 模型，先暂时关掉 drive 与 disorder，并只保留一维、单谐波 clean sector：

F = ∫ dx [ κ/2 (∂xφ)² + V0(1 − cos(nφ)) ]

在这个明确 normalization 下，相邻 minima 之间的 sine-Gordon kink 有特征宽度与壁张力：

ℓw = √[ κ / (n²V0) ]　；　γw = 8√(κV0) / n
公式边界：这两式只属于这里写出的 clean、单谐波、local-gradient 模型。真实 sliding-FE stacking landscape 若有方向各向异性、多谐波、非局域 elasticity 或多个 coupled interfaces，应重新对实际 energy landscape 做数值 wall calibration，不能把这两个 prefactor 当材料定律。

这两式立刻暴露 identifiability：只知道 wall width 时，只约束 κ/V0 的组合；如果还能独立知道 wall tension / wall energy，才有机会在这个简化模型里拆开：

V0 = γw / (8ℓw)　；　κ = n²ℓwγw / 8

4.5.2 · 哪个 observable 能约束什么？

observable / prior主要约束单独做不到什么
stacking symmetry / minima 数periodicity、允许的 n、order-parameter topology不能靠 hysteresis fit 把 symmetry 当自由参数随便调
clean wall width ℓwgradient stiffness / local barrier 的长度组合通常不能单独拆出 κ 与 V0
clean wall energy / tension γw√(κV0) 类型的能量组合没有宽度信息时仍不能唯一决定 κ、V0
stacking energy landscape / barrierlocal potential 的能量尺度与 harmonic content不决定 gradient stiffness κ
polarization amplitude / electrostatic coupling conventionP0 与 electric-drive energy scale不能从 coercive field 单独反推出 P0
clean-wall mobility / relaxation time在 statics 已冻结后的 Γ / kinetic scale若 κ、V0 还漂着，Γ 会与能量尺度互相补偿
P–E loop / coercive scaleprotocol 下多个机制的综合 response不能唯一同时识别 κ、V0、Γ、σ、ξd
disorder morphology + threshold statistics在 clean baseline 冻结后的 coupling law、strength、correlation effects不能用来补偿一个本来就错误的 clean wall

4.5.3 · 无量纲化的价值，是看见真正控制问题的 ratios

在上面的单谐波 clean model 中，可以用 ℓw 作为自然长度。于是很多“参数扫描”其实更应该写成 dimensionless ratio：

ratio物理含义数值上要问什么
dx / ℓw网格相对 wall core 的解析度wall 是否被足够多 grid points 解析
L / ℓwsystem size 相对 microscopic wall scalefinite-size scaling 是否真的离开 wall-core 尺度
ξd / ℓwdisorder correlation length 相对 wall widthwall 看到的是近白噪声、有限相关 defect，还是 smooth landscape
E P0 / V0drive coupling 相对 local periodic energy scale它只是自然 drive ratio，不自动等于 coercive / depinning field
σRF / V0 或 σRB / V0disorder energy scale 相对 clean barrier不同 coupling form 仍需 fair matching，不能只比同一个数字 σ
这正好把两处旧知识接起来：Grid sanity 负责“dx 改变时 physical disorder 是否保持不变”；Research Track fair matching 负责“RF 与 RB 是否在明确物理尺度上可比”。这里补的是更上游的一步：先把 clean energy / length scales 冻结。

4.5.4 · Γ 最好在 statics 冻结以后再校准

若采用 overdamped TDGL 形式 ∂tφ = −Γ δF/δφ，那么在这个 normalization 下，clean minimum 附近 local curvature 是 n²V0，小扰动的自然局域 relaxation time 满足：

τ0 ∼ 1 / (Γ n²V0)

这里的重点不是把这个 prefactor 当普适常数，而是说明 Γ 只有在能量尺度冻结后才有独立动力学意义。实际 calibration 更稳妥的做法，是先用 statics 决定 wall profile / energy，再用 clean-wall mobility 或独立 relaxation observable 约束 kinetic scale。

4.5.5 · calibration 与 validation 必须分开

① Structural prior

由 stacking symmetry / microscopic landscape 决定 order parameter 与 periodicity。

② Clean statics

用 wall width、wall energy、stacking barrier 等冻结 κ / V0 相关组合。

③ Clean dynamics

再用 mobility / relaxation 约束 Γ，不让 kinetic 参数替 statics 擦屁股。

④ Disorder

在 clean baseline 不动以后，定义 RF/RB coupling、physical amplitude 与 ξd。

⑤ Calibration set

明确哪些 observables 被用来定参数。

⑥ Holdout validation

用没参与校准的 morphology、threshold、size/temperature response 检查 model 是否真的预测到新东西。

一个常见自欺路径：同时调 κ、V0、Γ、σ 让同一条 P–E loop 很像实验，然后再把“loop 拟合得好”当成模型验证。那只是 calibration closure，不是 independent validation。
模型声明至少要补一句：“哪些参数由外部 structural / static / dynamic observable 约束；哪些只在 dimensionless ratio 中可识别；哪些仍是 phenomenological control parameter；最后用什么 holdout observable 验证。”

5 · Fedeli 2019：disorder 要进入“物理项”，而不是只给结果图加噪声

原文 · Fedeli, Kamlah & Frangi 2019　Smart Mater. Struct. 28, 035021 · Drive PDF

Different kinds of defects were considered: holes, point charges and polarization pinning in single crystals, as well as grain boundaries in polycrystals, without and with additional dielectric interphase.

It can be seen that defects lead to nucleation of new domains. Compared to the energy barrier for switching in an ideal single crystal, the overall coercive field strength is significantly reduced towards realistic values.

这一篇的价值是提醒你：不同 defect 类型对应不同物理耦合，不能全部塞进一个“noise strength σ”后还声称微观机制相同。
连续场里的做法物理含义与 06 的关系
V(φ,r) 或 α(r)、barrier(r) 随位置变局域 switching cost / wall energy 随位置变；若 ±φ 对称仍保留，常可看成 random-bond-like随机的是 landscape，不直接偏爱 + 或 −
−h(r)φ局域 bias 直接偏爱 order-parameter 的某个符号continuum random-field coupling；但不等同于“已经用了 RFIM”
固定区域 φ 或极大局域 barrierpinning centre / frozen region更接近强、局域、非高斯 defect，而不是白噪声
有限相关长度 hℓ(r)defect landscape 有真实尺寸 ℓdx 改变时必须保持 ℓ 的物理长度不变

Research bridge · disorder 至少有三条独立轴：coupling × strength × correlation length

只写“RF strength = σ”仍然少了一维信息。即使 coupling law 与 RMS strength 相同，只要空间相关长度不同，wall 看到的 energy landscape 就可以完全不同。最小写法是：

⟨h(r)h(r′)⟩ = Δ · C(|r−r′|/ξd)coupling type 决定 h 怎样进入自由能；Δ/σ 决定幅度；ξd 决定 disorder 在空间上是近似白噪声、有限尺寸 defect，还是 extended/clustered landscape。

δ-correlated limit

理想 continuum white noise 没有有限 microscopic ξd。离散成 cell-average local field 时，网格方差必须随 cell volume 重标度；二维对应标准差 ∝ dx−1。

finite-correlation disorder

若先定义一个物理 ξd 并生成连续 correlated field，dx refinement 的任务是更好地解析同一个 ξd；不能再机械把“每格 σ”按 white-noise 公式解释。

因此 correlated-RF robustness 不是“换一种随机数”。它是在问：当 disorder 本身带有一个新的物理长度 ξd 时，threshold、roughness 和 apparent exponent 是否只发生 nonuniversal shift，还是出现新的 crossover scale / mapping breakdown。
Research Track 的 fair matching 控制的是不同 coupling 的比较尺度；本节补上第三轴 ξd。二者一起才能把“same disorder strength”说完整。

6 · 最容易把数值结果做假的地方：dx 改了，disorder 也跟着变

下面不是某篇论文的直接原句，而是本站对 continuum white disorder 的离散化推导。它是做 convergence test 前必须固定的量。

⟨h(r)h(r′)⟩ = Δ δ(d)(r−r′)　⇒　Var(hcell) = Δ / dxd因此 cell/node 上使用独立 N(0,1) 时，为保持 continuum Δ 不变：σgrid = √Δ · dx−d/2。二维就是 σgrid ∝ 1/dx。
二维关键结论：如果代码写成 h = σ * normal()，然后把 dx 从 1 改成 0.5 却保持 σ 不变，你并没有只“加密网格”；你同时把 continuum disorder strength 改弱了。反过来，若目标是固定物理白噪声强度，应让输入标准差按 1/dx 缩放。
适用范围：上面的 σgrid ∝ dx−d/2 针对的是把 δ-correlated continuum field 离散成每个网格单元的 cell-average / 等价局域场这一约定。若 disorder 有有限相关长度、是固定位置/固定强度的 defects，或代码中的随机量代表对一个 cell 已积分的能量/力而不是局域 field value，就不能机械套用同一缩放；应从实际使用的 covariance 或离散能量项重新推导 dx dependence。

白噪声 disorder

固定的是 Δ，而不是数组里每个 pixel 的标准差。一般 d 维下，std ∝ dx−d/2。

有限相关长度 disorder

先定义物理 correlation length ℓ 和 covariance，再离散。只要 dx 足够解析 ℓ，就不应把它继续当 δ-correlated noise 用同一缩放规则硬套。

6.2 · Thermal noise / FDT：温度不是再加一张随机场

quenched disorder 与 thermal noise 都会在代码里出现 random numbers，但物理角色完全不同：quenched field 在一次 run 内固定；thermal noise 随时间刷新，并且其幅度必须与 mobility、temperature、空间 cell measure 和 timestep 一起满足 fluctuation–dissipation convention。

Quenched disorder

描述 frozen landscape。一个 realization 生成后整条 trajectory 都使用同一 h(r) / δV(r)。白噪声空间归一化涉及 cell measure，但没有 temporal δ-function。

Thermal noise

描述与 heat bath 相连的快速随机力。white-noise idealization 同时在 space 与 time 上 δ-correlated；改变 dx 或 dt 都会改变离散采样幅度。

6.2.1 · 先声明连续方程，再写离散随机数

对 constant-mobility、additive-noise 的 overdamped TDGL / Model-A convention：

∂tφ(r,t) = −Γ δF/δφ + ξ(r,t)
⟨ξ(r,t)⟩ = 0　；　⟨ξ(r,t)ξ(r′,t′)⟩ = 2Γ kBT δ(d)(r−r′) δ(t−t′)

这一定义把 thermal bath 的噪声强度和 dissipative mobility Γ 绑在一起。若模型使用 dimensionless energy / temperature，或 Γ 的定义放在方程另一侧，prefactor 必须跟着该 normalization 重新推导；不要从别人的代码里抄一个 sqrt(T)。

适用边界：这里讨论 constant Γ + additive Gaussian white noise。若 mobility 依赖 φ、噪声是 multiplicative / colored，或使用不同 stochastic calculus，漂移项与 FDT 关系会改变，不能机械套下面的离散式。

6.2.2 · derivative noise 与 update noise 的 dt 标度正好相反

设一个离散 cell 的 measure 为 ΔV（二维有效模型可对应 ΔA，但必须和 F 的积分单位一致），时间步为 Δt。若代码每一步先生成“方程右端的 noise rate” ξim：

Var(ξim) = 2Γ kBT / (ΔV Δt)

所以 rate amplitude 随 Δt−1/2 增大；但 Euler update 真正加到 φ 上的是 ξΔt，因此随机 increment 满足：

Δφthermal = √[2Γ kBT Δt / ΔV] · N(0,1)

也就是说 update amplitude 随 Δt+1/2。这两个写法等价，但不能混用。很多“dt convergence 一改温度就变”的 bug，就是把 derivative amplitude 当 increment amplitude。

代码里随机数加在哪里正确 white-noise 尺度常见错误
加到 dφ/dt 右端std ∝ [ΓT/(ΔVΔt)]1/2dt 改了仍固定同一个 noise-rate std
直接加到每步 Δφstd ∝ [ΓTΔt/ΔV]1/2又额外乘一次 dt，或完全不随 dt 变
二维 cell-averageΔV → ΔA = dx²（按你的 2D energy convention）把 quenched RF 的 1/dx 规则直接当完整 thermal-noise rule

6.2.3 · dx convergence 与 dt convergence 都要保持同一个 T convention

dx test：若 physical coarse-grained free energy 与 temperature convention 固定，cell 变小后 thermal noise rate 的方差会随 1/ΔV 增大；不能固定每格 random amplitude。
dt test：减小 dt 时，noise rate std 应按 dt−1/2 调整，或 update std 按 dt+1/2 调整；两种实现只选一种。
equilibrium sanity：在 E=0、无 quenched disorder 的简单可控 case 下，先检查 steady fluctuations / distribution 是否随 dt refinement 稳定，再进入 driven problem。
driven sanity：有外场时系统不是 equilibrium，但 thermostat 的 noise–dissipation convention 仍要固定；不能为拟合 creep / rounding 曲线事后改 noise amplitude。
更深一层：continuum white thermal noise 本身含有任意短波 fluctuation，phase-field 又是 coarse-grained theory。因此极端 dx→0 不一定意味着所有 bare parameters 都能原封不动保持；网格 cutoff 与 coarse-graining convention 要写清。这里的首要目标不是追求“随机场逐点收敛”，而是保证目标 observables 在声明的 coarse-grained model 下稳定。

6.2.4 · thermal seed 仍然只是 inner repeat

同一个 quenched landscape 下换 20 个 Langevin seeds，可以更精确估计该 landscape 的 finite-T conditional response；它不会自动变成 20 个新的 disorder realizations。统计层级继续沿用 Research Track：

quenched source i → thermal seeds j → trajectory frames t
Research Track：finite-T protocol / outer-vs-inner statistics　·　Module 05：thermal rounding measurement logic
代码验收一句话：改 dx 或 dt 后，如果你不能明确说明“为了保持同一个 physical T，随机项到底按什么公式重标了”，finite-T exponent 暂时没有解释资格。

6.3 · Steady-wall velocity contract：一个 v(E) 点到底怎样才算“测到了”？

depinning 最常见的下一步是画 v(E)，但“trajectory 最后动了一点”并不等于得到 steady velocity。尤其靠近 Ec 时，长 transient、intermittent bursts、有限 observation time 与 wall-topology change 都会把一个单点速度变成分析自由度。这里把 run 是否有效、wall 怎样位移、什么时候进入 steady window、单条 trajectory 的误差和跨 disorder source 的误差 分开。

为什么要这么严格：Module 05 的 Ferrero 2013 已经显示，depinning 附近可以存在很长的 nonsteady crossover；过早把 transient 当 asymptotic regime，会系统性偏置 effective exponent。steady-v route 与 nonsteady-relaxation route 都可以研究 criticality，但不能把两套 estimator 混在同一条 β fit 里。

6.3.1 · 先定义一个可 unwarp 的 wall coordinate

如果 wall extraction gate 已经通过，可以先把单值 wall 写成 u(y,t)，再定义 center-of-mass coordinate：

X(t) = ⟨u(y,t)⟩y　；　v = dX/dt

若驱动方向使用 periodic boundary，X(t) 必须先做 unwrapping；否则 wall 穿过边界时，坐标会从 L 跳回 0，一条真实匀速轨迹会被错误地拟合成巨大反向速度。若体系包含两堵对称 wall，则必须预先规定测哪一堵、还是测 wall separation；不能在分析时按“哪条更漂亮”选择。

不要用错误的 surrogate：平均 |∂φ/∂t|、总 switching activity、dP/dt 可以很有用，但它们不是自动等于 wall center-of-mass velocity。bulk relaxation、局域 breathing、nucleation 都可能贡献这些量。

6.3.2 · steady window 必须由稳定性判据产生，不是肉眼裁一段直线

对每个 constant-E run，先保留完整 X(t)，再注册一族 nested candidate windows。例如固定终点 t2，逐步增加 transient cut t1，对每个窗口拟合：

X(t) = X0 + v t　，t ∈ [t1, t2]
检查通过意味着什么失败时怎么处理
window stability继续向后移动 t1 时 v 不再系统漂移标记 transient / unresolved，不挑一个最顺的窗口
late-window split后半段拆成两个或多个子窗口，局部 slope 相容可能有 aging、late burst 或尚未稳态
net displacement累计位移明显大于 wall-core / extraction jitter scale不能用极小净位移制造“非零速度”
topology gate整个测量窗口仍是一堵可追踪的 wallbubble / extra wall / persistent overhang 出现时停止 elastic-line velocity claim
窗口长度不是越长越自动正确。靠近 threshold，长等待后突然移动可能是有限温度激活、有限系统一次性 escape，或真正 steady intermittent motion；必须结合 T、boundary、exposure 与重复 source 判断。一个长 run 的很多 time points 仍然只是一个 run，不会把 outer n 变大。

6.3.3 · 用 slope，还是用总位移 / 总时间？两者要互相复核

在真正 steady 的长期窗口里，线性回归 slope 与 endpoint estimator

vend = [X(t2) − X(t1)] / (t2 − t1)

应给出相容结果。二者明显分裂时，通常意味着窗口内仍有 curvature、长停滞或单次 burst 主导。此时不要把 regression 的很小标准误当成“v 很精确”：time samples 强相关，ordinary least-squares pointwise error 不是 disorder uncertainty。

6.3.4 · 一个 field point 的统计层级

quenched source i → constant field E → trajectory Xi,E(t) → source-level vi(E)

如果同一个 quenched source 在多个 E 上重复，得到的是一条 source-specific velocity curve，这些 field points 在统计上相关。真正做 population-level v(E) 或 β inference 时，outer independent unit 仍然是 quenched source；trajectory frames、多个 fit windows、同一 source 的多个 E 都不能各自冒充新的 n。

推荐保存

raw/unwrapped X(t)、wall-valid mask、transient cut、candidate-window slopes、final window、endpoint velocity、topology/QC status 与 exposure。

推荐报告

每个 source 的 vi(E)，再跨 source 给 summary/CI；β fit 继承冻结的 Ec authority 与预注册 reduced-force window。

6.3.5 · pinned、moving、unresolved 与“v≈0”不是同义词

run outcomevelocity estimator能否进入 β fit
resolved-moving + steady-window pass有资格给 source-level steady v满足冻结 fit window 时可以
resolved-pinned under registered exposure不是“测得一个精确 v=0”用于 threshold/bracket，不作为 log-v power-law 点
late motion / exposure-limitedunresolved / censored不能硬塞成 0 或删掉不提
numerical-invalid无物理 velocity estimate绝不能当 pinned
topology-breakdown原来的 single-wall v 定义失效转向 bulk/multidomain observable 或单独 breakdown analysis
先看 Module 05 的 threshold inference ladder：它负责判定每个 run 有没有资格进入 threshold authority；本节负责 threshold 以上的 run 怎样获得可审计的 steady v。两条链闭合后，β 才真正有输入数据。
steady-v 验收一句话：如果一个 v 点不能回答“wall coordinate 怎么定义、是否 unwrap、丢了多少 transient、换 late window 后 slope 是否稳定、wall topology 是否仍有效、outer independent unit 是谁”，它暂时不该进入 universality fit。

6.5 · 从 diffuse phase field 提取 u(y)：先证明“这是一堵线”

phase field 原始自由度是二维 φ(r,t)，elastic-line observable 却假设一维单值 u(y,t)。这一步是一次 model reduction，不能只写一句“取 φ=0 contour”。对周期 stacking coordinate，零点甚至未必总是两个目标 basin 的物理中点；应先定义要分开的两个 states，再指定 separator。

① level-set sensitivity：在 wall core 内选一组相邻 contour thresholds；u(y)、mean velocity 与 roughness scaling 若对小幅阈值变化明显漂移，说明提取仍受 diffuse-core / discretization 控制。
② intersection count：逐个 y 统计 contour 与横截线交点数。0、1、>1 分别对应缺失、single-valued、overhang/multiple-wall 候选；报告非 1 的比例，而不是静默选其中一个交点。
③ topology cross-check：同时监测 bubble / detached island / extra-wall component。projected u(y) 可以在图上很平滑，却把真实二维拓扑丢掉。
④ area-based cross-check：用 domain-area change 得到一个不依赖单值 contour 的平均推进量，与 u(y) center-of-mass velocity 比较；两者明显分叉时先查 topology，而不是继续拟合 β。
⑤ roughness triple：在通过 topology gate 的数据上同时检查 W(L)、B(r)、S(q)，并标出 grid-scale、wall-width 与 system-size cutoff。
Zhou 2009 给出的反例很具体：driven RFIM 在 depinning 附近因为 overhangs 出现 intrinsic anomalous scaling / multiscaling；也就是说“墙还能画出来”不等于“墙仍属于单值 elastic manifold”。去 Module 05 看 exponent robustness →
Threshold 不从一张 v(E) 图里“读出来”：先做 E=0 stability / numerical certificate，再把每个 field run 分类为 resolved-moving、resolved-pinned-under-exposure、unresolved、numerical-invalid 或 topology-breakdown；只有有效 pinned / moving 才能缩 bracket。去 Module 05 看完整 threshold inference ladder →

6.6 · Run receipt / provenance：一张图能不能成为证据，先看它能不能追到 run

只保存一个 .npz、一张 PNG 或最终 CSV，并不等于结果可复现。真正可审计的链条应该能从 figure / estimator 一路反查到：哪版代码、哪份实际生效的配置、哪组随机源、怎样结束、保存了什么 raw output、又由哪版分析规则压成当前数字。 这份绑定记录就是 run receipt。

最小原则：raw bytes 可恢复 ≠ run 可重算；run 可重算 ≠ estimator 可复核；全部可复核 ≠ 它自动拥有当前 claim authority。

6.6.1 · 一个 simulation run 至少要冻结七层信息

Code authority：repository / commit 或 source-tree hash；明确 clean / dirty。若运行来自 dirty working tree，应保存 patch / tree hash，并把它标成 dated snapshot，而不是假装属于某个干净 commit。
Resolved configuration：保存 defaults、include、CLI override 全部展开后的最终配置。至少包含 geometry、boundary condition、L / N、dx、dt、T、drive protocol、disorder law / strength / correlation、initial condition 与 units。
Random identity：把 quenched-disorder seed 与 thermal / stochastic seed 分开记录；需要时同时保存 RNG family / stream convention。一个整数 seed 只有在随机流定义也固定时才真正可复现。
Execution environment：solver / integrator、precision、backend、关键 dependency / environment identity。硬件型号通常不是 physics parameter，但 precision、backend 或 library change 若会改变数值路径，就必须可追踪。
Stop & QC receipt：为什么停止——converged、hit exposure limit、max steps、numerical failure、manual abort？同时保存 NaN/divergence、residual、wall-topology 等与物理判读直接相关的 QC。
Raw-output receipt：原始数组 / trajectory / checkpoint 的路径或 object id、sampling cadence、shape、dtype、units 与 checksum。derived CSV / PNG 应指回 raw parent，而不是成为孤儿证据。
Estimator receipt：analysis code/version、输入 run IDs、transient cut、fit window、wall-extraction rule、threshold criterion、censoring rule、bootstrap / resampling unit。最终一个 β 或 ζ 必须能反查这些选择。

6.6.2 · 不要用一个 status 字段装下三种完全不同的问题

状态轴它回答什么例子绝不能偷换
execution_status数值任务是否按实现要求完成completed / aborted / numerical-invalidnumerical-invalid ≠ physically pinned
physical_assessment在注册 protocol 下物理状态能判到哪一级resolved-pinned / resolved-moving / bracketed / censored / unresolved / topology-breakdowncensored ≠ no transition exists
analysis_role这条 run 在推断里扮演什么角色primary / sensitivity / holdout / post-hoc diagnostic / excluded-with-reasonpost-hoc diagnostic ≠ preregistered primary evidence
为什么要拆三轴：一个 task 可以数值上完全成功，却因为 observation time 不够而在物理上 unresolved；也可以物理上很清楚，但只属于 sensitivity analysis。把它们都压成 PASS / FAIL，会在后续 population statistics 里把“没有证据”误写成“负证据”。

6.6.4 · receipt 应该沿着分析链继续传递，而不是在 raw run 处断掉

Run receipt

代码、resolved config、RNG、status、raw hashes。

Estimator receipt

从哪些 runs、用什么 rule / window 得到一个 observable。

Figure / claim map

panel 指向 estimator 与 independent evidence unit；正文 claim 再指向 panel。

source authority → resolved run receipt → raw data → estimator receipt → figure source map → claim

这条链有一个重要但常被忽略的结论：reproducible 不等于 authoritative。 历史 run、exploratory script 或 candidate figure 可以保存得非常完整，但如果它没有通过当前 analysis contract，就应该被保留用于 recovery / context，而不是悄悄升级成当前主结论。

这和 Research Track 的 Data → Estimator → Evidence → Claim contract 正好闭合：那里规定“什么能支持什么 claim”，这里规定“每一级证据怎样留下可追溯 receipt”。

7 · 一套不会自欺的 depinning 数值实验

① 先造一堵墙

用两畴初态或边界条件得到单一 diffuse wall；先在无 disorder、无 drive 下检查 wall width 与静态稳定性。

② 再加 quenched disorder

明确 RB / RF / strong defects 的物理定义；固定 physical strength 与 correlation length，而不是固定 pixel amplitude。

③ 最后扫 constant drive

为了 depinning，优先恒定 E 的单壁实验；P–E triangular loop 可以保留给 switching phenomenology，但不拿它替代 v(E) threshold experiment。

dx convergence：至少保证 wall width 被多个 grid points 解析；同时按物理定义重标 disorder。
dt convergence：减小 dt 后 Ec、v(E)、roughness 不能系统漂移。
size convergence：测多个 L；临界附近 ξ 会增长，单一尺寸的 β 拟合不够。
seed statistics：报告 disorder realizations，而不是只挑一张“漂亮的 wall”。
wall extraction：先定义两个目标 basin 之间有物理意义的 level set / separator，再检查 contour-threshold sensitivity；只有通过 single-valuedness gate 后才压成 u(y)。
observable chain：Ec → v∼(E−Ec)β → B(r)/S(q) → finite-size scaling；每一步都有独立 sanity check。
最终要能说出一句完整的模型声明：“我模拟的是哪一级自由度；disorder 的 continuum 定义是什么；dx 改变时哪些输入随之重标；在哪些尺度 wall 可以约化成 elastic interface；一旦出现哪些几何结构，这个约化就停止可信。”
到这里，01–07 的基础链已经闭合：stacking → switching pathway → domain wall → pinning/creep → depinning → disorder/RFIM → numerical model。Module 08 不再补基础课，而是拿这套检查表重新审 2025–2026 的 sliding-FE 最新工作：它们到底已经测到了什么，还缺哪些 universality evidence。
