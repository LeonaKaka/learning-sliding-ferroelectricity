1 · 无序 is not one number：σ 之前先问“随机了什么”

传统铁电已经给出一个很强的提醒：无序 不是只用一个幅度参数描述。Jesse et al. 2008 从正、负 局域 成核 偏置 中分别重建 无序 势 的 随机场 与 随机键 分量；Ovchinnikov et al. 2009 又进一步说明 滞回 形状 本身携带 无序类型 与 强度 的信息。对 滑移铁电 来说，更不能先把所有 缺陷 压成“一个 σ”，再讨论谁更强。

耦合 type

无序 是直接偏爱某个 局域状态，还是改 势垒 / 刚度 / 迁移率 / 几何？

强度

RMS、energy 方差、局域力 RMS 等不同定义并不自动等价。

关联长度

白噪声无序 与 有限尺寸 缺陷 即使 RMS 相同，也可能产生不同 集体动力学。

实验锚点Jesse et al., Nature Materials 7, 209–215 (2008)

作者直接从 局域 成核 biases 提取 随机键 与 随机场 无序 分量。DOI 10.1038/nmat2114

inference anchorOvchinnikov et al., PRL 103, 157203 (2009)

在 随机键–随机场 Ising 框架 中，用 滞回回线 形状 识别 无序类型 / 强度；它证明“回线 形状 含 无序 信息”，但不意味着真实 滑移铁电 自动服从同一 Ising 模型。DOI 10.1103/PhysRevLett.103.157203

因此真正公平的问题不是“RF 的 σ 和 RB 的 σ 谁大”，而是：在明确的 匹配规则 下，改变 耦合形式 本身是否仍改变 翻转？

1.1 · 一个适合 滑移铁电 的有效比较语言

Additive 随机场型 耦合
FRF = −h(r) cos[φ−α(r)]

局域 广义力 / 力矩：
τRF ∝ −h sin(φ−α)。它可以直接偏置 局域相位 坐标。

势垒-amplitude / 随机键型 耦合
FRB = δV(r)[1−cos(nφ)]

局域 广义力 / 力矩：
τRB ∝ −nδV sin(nφ)。它主要修改 periodic 景观 的 势垒 / 曲率。

术语纪律：这里的 “随机场型 / 随机键型” 指 连续体 有效 耦合。它不等于说模型已经变成 RFIM，也不意味着真实 缺陷 只有这两种 微观 来源。
匹配规则优点局限
same 参数 标准差代码最简单不同 耦合 函数 下通常没有明确“等强”物理意义
same energy 方差比较 energy 景观 涨落动力学由 derivative / force 决定时仍可能不公平
same phase-averaged 局域-force RMS直接对齐 动力学方程 里 无序 force 尺度依赖选定 相位测度；不能抹掉 耦合 形式 的差异

最后一种尤其适合回答“把局域 force 尺度 对齐以后，耦合形式 还重要吗？”——但 匹配 是控制变量，不是理论上保证两个 无序 动力学等价的变换。

2.5 · 温度 是新的实验轴，不是把 随机种子 多跑几次

当 孤立畴壁 T=0 方案 稳定以后，有限温度自然分成两个不同的问题：

Deep 阈值以下 · 蠕变

f<fc 且离阈值足够远：问 热激活 barriers 是否产生可测的长期 漂移，是否存在稳定 蠕变 区间 与 μ 候选。

Near 阈值 · 热圆滑

f≈fc：问 T=0 singularity 怎样被温度圆滑，是否存在 v(fc,T)∼Tψ 与 joint 场–温度 scaling。

3 · 从 堆垛构型 到 最小 滑移铁电 相场

普通 φ⁴ 相场 能教 界面 动力学，却容易把 滑移铁电 最重要的“周期性 堆垛 坐标”藏掉。一个更贴近本项目问题、但仍保持 最小 的教学模型，是把 局域 registry 压成周期变量 φ(r,t)，再把 极化 写成 φ 的周期函数。

P(φ)=P0 sinφ
F[φ]=∫d²r { κ/2 |∇φ|² + V0[1−cos(nφ)] − E P0sinφ + Fdis[φ,r] }
项保留的物理它没有自动包含什么

3.1 · 离散化 不是纯数值细节

⟨h(r)h(r′)⟩=Δδ(d)(r−r′) ⇒ std(hcell)∝dx−d/2二维 cell-average white 无序：std ∝ 1/dx。该缩放只针对明确的 δ-correlated continuum-field convention。

因此 dx 收敛 要固定的是 物理 无序 定义，不是数组每个 像素 的 标准差。有限相关长度 缺陷、固定位置 缺陷、网格单元积分 random energy 都必须重新从 协方差 / 离散能量 定义推导。

4.7 · 数据 → 估计量 → 证据 → 结论：先知道 n 在哪一层

一条研究结论不是从 原始文件 直接跳到 论文表述。中间至少有四层：数据对象 是记录到的东西；估计量 把它压成一个可比较的量；证据单元 决定不确定度和独立样本数；最后才是 结论。最常见的伪精确，来自把这四层混在一起。

数据

轨迹、场 row、帧、endpoint、事件、运行 状态。

估计量

fc(i)、v、βeff、ζ、work、事件-size statistics。

证据

哪些 无序样本 / device / size 真正提供独立信息。

敏感性

区间、阈值、事件检测器、拓扑、观测时长 改动后是否 通过。

结论

从 现象学 到 候选 临界性，再到 普适性。

4.7.2 · 阈值 结果必须保留 失败状态语义

运行 / search 状态允许进入的 估计量正确解释

绝不做的事：把 未解析 样本删掉直到图变漂亮；把未 bracket 的 样本 随便赋成 Emax；或者把 数值失败 解释成“墙被钉住”。这些都会直接偏置 总体 fc 与后续 β。

雪崩统计冻结的 事件 事件检测器 / size 定义截止、alternative-distribution 检验、形状 checks看到 指数 后再改 merge/死时间 rule
这叫 依据 链：下游分析可以对上游 uncertainty 做 敏感性 传播，但不能把上游 估计量 当成隐藏自由参数重新优化。否则同一批数据会被多次“用来证明自己”。

4.7.4 · 结论 ladder：失败时知道该退到哪一级

证据层级最低要求允许的写法

E3 · cross-可观测量 临界证据fc、β、ζ、ν/z 中多个独立 可观测量 相互兼容候选 退钉扎 临界区间
E4 · 普适性 / 失效标度关系、坍缩、拓扑 判据、修正 与替代解释一起 通过候选 普适类；或明确 映射 失效
失效 不是“没做成”。 如果 β/ζ/ν 无法在同一 依据 链 下相容，或 拓扑 判据 系统失败，正确结果可能就是：该 滑移铁电 区间 只能称为 退钉扎-like / 有效-界面 交叉区，而不是强行给它套 普适性 标签。
公开边界：这里给的是可复用的 分析约定，不展示项目未发表数值、内部 批次标签 或当前 判据 状态。真正分析时再把每个 数据集 映射到这张表。上游每个 simulation 运行 还必须能回答“它到底由哪版代码、哪份 最终生效配置、哪组随机源与哪种停止状态生成”；去 Module 07 看 run receipt / provenance contract →

4.8 · 配对 & 分层 uncertainty：同一 来源 内做差，跨 来源 才谈 总体

“匹配比较” 不只是在横轴上把两个参数调到同一个数。若 A/B 两个 耦合 能由同一个预先定义的 潜在 来源 生成，配对设计 可以先消掉 无序样本-to-无序样本 的大波动，再问 耦合形式 本身改变了多少。但 配对 是实验设计，不是事后统计技巧：必须在看 outcome 前定义，而且不能跨本来就不可交换的 证据 strata 强行配对。

Δi = yA,i − yB,i　；　Δ̄ = N−1 Σi=1N Δi

这里真正进入 总体推断 的基本对象是独立 来源 i 的 配对差值 Δi，不是 A/B 两边所有 time rows 的总和。

4.8.1 · 配对 什么时候是公平的？

Same nuisance 来源

两条 条件 共享的是你想消掉的 干扰波动，例如同一独立 无序 来源 / device，而不是为了让结果相似才事后挑最接近的 pair。

Frozen 映射

从 潜在 来源 到 A/B 无序样本 的变换必须预先定义，并保持各自目标 边缘分布 / 匹配 contract；“同 随机种子”本身不自动等于公平。

Same 证据 stratum

production、holdout、successor、legacy 或不同 方案 若 依据 不同，就不能只因为能找到共同标签而塞进一张 配对表。

共同随机数 是 方差降低 device，不是物理等价证明。 配对 能让 within-来源 差值 更精确，但不能抹掉 A/B 耦合 的不同数学结构，也不能替代 fair 物理 匹配。

4.8.2 · 外层 样本 与 内层 重复 要分开

层级典型对象主要用途不确定度怎么处理
外层 独立单元独立 无序样本 / independent device总体推断CI / 自助法 / 模型 的最外层 重采样单元
配对条件同一 来源 下 A vs B 耦合 / 方案within-来源 差值先在 来源 内形成 Δi，再跨 i 汇总
内层 stochastic 重复固定 quenched 景观 下的 热 随机种子估计 条件 热 expectation / 随机波动先在 i 内平均或做 nested 模型；不能冒充新 无序 样本
重复观测time rows、cycles、帧、事件估计 轨迹 / 事件 distribution / morphology保留 clustering；不能用 row count 放大 总体 n
自助法 drawresampled index sets传播 估计量 uncertaintydraw 数量只控制 蒙特卡洛精度，不增加物理样本

4.8.3 · 有限温：先在 淬火无序样本 内平均，再跨 来源 推断

ȳi,c = Mi,c−1 Σj yi,c,j　；　Δi = ȳi,A − ȳi,B

其中 i 是 quenched 无序样本，j 是 热 随机种子，c 是 条件。若研究问题是“平均 热 response 在不同 耦合 间是否不同”，最简单的 依据 是先得到每个 i,c 的 条件 估计量，再对 Δi 做 外层层级 inference。若 内层 随机方差 本身也是科学问题，可用 分层 / nested 自助法，但外层独立单位仍然是 i。

不要把更多 热 随机种子 当成更多 无序。 增加 内层 重复 会降低给定 景观 下 热 均值 的 蒙特卡洛 噪声，却不能凭空增加对 无序总体 的覆盖。

4.8.4 · 缺失 / censored pair 不能靠“补一个数”恢复完整

情况错误处理正确方向
A 有 有效估计，B 只有 下界把 B=Emax 后直接算 Δ保留 配对 删失 / bound 信息；若主 估计量 不支持，降级为 部分信息分析
A 数值无效，B valid把 A 当 钉扎态 或从 配对 样本 静默删除记录失配原因；区分 technical 缺失机制 与 物理 删失
某 来源 只有一侧通过 拓扑 判据只保留“好看”的另一侧 几何 指数该 配对 几何 差值 不成立；保留 失效 / 缺失机制 本身
多个 结果 同时显著把每个 差值 当独立发现预定义 主 族，必要时 多重比较控制；同时报告 effect / CI

4.8.5 · 有限尺寸 也有 配对 陷阱

为了降噪，有时会让不同 L 使用相关的 无序 construction，例如从同一个大 场 crop / restrict 出较小系统。这样做不是禁止的，但会让不同 L 的 估计量 相关；此时“每个 L 一点”不能被当成互相独立的样本。若目标是最简单透明的 有限尺寸推断，优先让每个 L 有独立 无序 无序样本；若有意使用 共同随机数 / 嵌套尺寸设计，就把 关联 structure 写进 记录 和统计模型。

最实用的统计顺序：先决定 独立单元 → 再决定哪些 条件 在 unit 内 配对 → 再处理 热/事件/cycle 等 内层 重复 → 最后才选择 自助法 / 分层 模型。反过来先把 CSV 全部堆进统计包，几乎一定会把 n 算错。
这节与 Data → Estimator → Evidence → Claim 是同一件事的统计版本；而每个 外层 / 内层 身份怎样被保存，则回到 Module 07 的 run receipt。

5 · 机制证伪：先排掉简单解释，再谈“真正机制”

研究型阅读与普通教材最大的区别之一：数据往往更擅长否定一个过于简单的机制，而不是直接唯一确定微观机制。

假说 A：无序 只增加一个统一 delay

预期：不同 强度 下 temporal 排序 应保持同一方向，主要只是整体变慢/变快。

若 排序 随 强度 / 翻转 stage 改变：可以排除一个 与强度无关 标量延迟图像；但还不能因此命名唯一新机制。

假说 B：某种 耦合 永远“更碎”

预期：分量 count、界面 density、largest-分量 比例 应给出跨 stage 一致的 碎裂 排序。

若不同 morphology metrics 不给统一 排序：应放弃单一 碎裂 cartoon，转向 阶段依赖 路径。

最重要的研究纪律：“simple 机制 被 证伪”本身就是结果。不要为了让故事看起来更完整，立即用另一个没有被独立测量的 机制 填空。
