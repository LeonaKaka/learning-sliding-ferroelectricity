1 · 无序不是一个数：σ 之前先问“随机了什么”

传统铁电已经给出一个很强的提醒：无序不能只用一个幅度参数描述。Jesse et al. 2008 从正、负局域成核偏置中分别重建无序势的随机场与随机键分量；Ovchinnikov et al. 2009 又进一步说明滞回形状本身携带无序类型与强度的信息。对滑移铁电来说，更不能先把所有缺陷压成“一个 σ”，再讨论谁更强。

耦合类型

无序是直接偏爱某个局域状态，还是改变势垒 / 刚度 / 迁移率 / 几何？

强度

RMS、能量方差、局域力 RMS 等不同定义并不自动等价。

关联长度

白噪声无序与有限尺寸缺陷即使 RMS 相同，也可能产生不同集体动力学。

实验锚点Jesse et al., Nature Materials 7, 209–215 (2008)

作者直接从局域成核偏置提取随机键与随机场无序分量。DOI 10.1038/nmat2114

推断锚点Ovchinnikov et al., PRL 103, 157203 (2009)

在随机键–随机场 Ising（伊辛）框架中，用滞回回线形状识别无序类型 / 强度；它证明“回线形状含无序信息”，但不意味着真实滑移铁电自动服从同一 Ising 模型。DOI 10.1103/PhysRevLett.103.157203

因此真正公平的问题不是“RF 的 σ 和 RB 的 σ 谁大”，而是：在明确的匹配规则下，改变耦合形式本身是否仍改变翻转？

1.1 · 一个适合滑移铁电的有效比较语言

加性随机场型耦合
FRF = −h(r) cos[φ−α(r)]

局域广义力 / 力矩：
τRF ∝ −h sin(φ−α)。它可以直接偏置局域相位坐标。

势垒振幅 / 随机键型耦合
FRB = δV(r)[1−cos(nφ)]

局域广义力 / 力矩：
τRB ∝ −nδV sin(nφ)。它主要修改周期景观的势垒 / 曲率。

术语纪律：这里的 “随机场型 / 随机键型” 指连续体有效耦合。它不等于说模型已经变成 RFIM，也不意味着真实缺陷只有这两种微观来源。
匹配规则优点局限
相同参数标准差代码最简单不同耦合函数下通常没有明确“等强”物理意义
相同能量方差比较能量景观涨落动力学由导数 / 力决定时仍可能不公平
相同相位平均局域力 RMS直接对齐动力学方程里的无序力尺度依赖选定相位测度；不能抹掉耦合形式的差异

最后一种尤其适合回答“把局域力尺度对齐以后，耦合形式还重要吗？”——但匹配是控制变量，不是理论上保证两种无序动力学等价的变换。

1.2 · 为什么这在真实滑移铁电里不是纯数学游戏

2026 年 CVD 生长 3R-WSe₂ 工作明确报告：生长诱导结构无序会显著影响极化翻转，且多畴动力学控制铁电响应的演化。这类实验告诉我们“无序确实重要”，但从结构无序到 RF / RB / 迁移率 / 几何无序的粗粒化仍需逐项论证。

滑移铁电锚点Paul et al., Nanoscale (2026), DOI 10.1039/D6NR01832G

适合作为“真实滑移铁电为什么必须研究无序”的材料学锚点；它不直接替我们决定该用哪一种有效无序项。

真实非均匀性首先可能影响不要自动等同于
封闭小畴 / 粗糙边缘局域势垒、几何、畴壁曲率Gaussian white random field（高斯白噪声随机场）

应变 / 堆垛非均匀性周期景观、畴壁能量、偏好堆垛单一标量 σ

2 · 完整翻转与孤立畴壁退钉扎：不是同一套实验换个名字

这是研究路线里最重要的方案区分。三角波滞回很适合研究完整翻转体系；但如果问题变成“一个预先存在的畴壁是否存在临界退钉扎”，就必须尽量把成核、多畴路径与历史混合因素拿掉。

完整翻转 / 滞回孤立畴壁退钉扎
初态单畴 / 混合畴，可允许翻转拓扑自己发展明确构造并先弛豫一堵预存畴壁
驱动三角波 / 周期 E(t)恒定 E
主要输出P(E)、矫顽尺度、回线功、翻转活动度、形貌u(y,t)、稳态 v(E)、B(r)、S(q)、Ec(L)
阈值含义方案依赖的翻转 / 矫顽阈值在定义的 T=0 畴壁问题中钉扎态→运动态阈值
β不能由回线的 Ec 直接得到在稳定的稳态速度区间中测试 v∼(E−Ec)β
主要风险成核、路径历史、多个畴壁混在一起瞬态、有限尺寸、畴壁拓扑失效
一句话：矫顽场可以是非常有用的翻转可观测量，但不能因为数值上“像一个阈值”就重命名成退钉扎临界场。
① E=0 弛豫

先确认初始畴壁自己不会因为准备方式继续漂移。

② 恒定 E

每个场独立测长期畴壁轨迹，而不是从扫场中截一段。

③ 稳态速度判据

排除明显瞬态；低于阈值要区分确实钉扎态与观测时长不足。

④ 拓扑判据

出现持续封闭小畴 / 悬垂 / 成核时，不再盲目把畴壁写成单值 u(y)。

2.5 · 温度是新的实验轴，不是把随机种子多跑几次

当孤立畴壁 T=0 方案稳定以后，有限温度自然分成两个不同的问题：

远低于阈值 · 蠕变

f<fc 且离阈值足够远：问热激活势垒是否产生可测的长期漂移，是否存在稳定蠕变区间与 μ 候选。

临近阈值 · 热圆滑

f≈fc：问 T=0 奇异性怎样被温度圆滑，是否存在 v(fc,T)∼Tψ 与联合场–温度标度。

层次应该固定什么重复什么独立统计单元
淬火无序一个景观 h(r)/δV(r)换无序随机种子用于无序总体推断的外层单元
热噪声同一个淬火景观换 Langevin（朗之万）/ 噪声随机种子同一景观内的条件重复
轨迹帧同一次运行随时间采样不是新的无序样本
最重要的防过拟合规则：热圆滑必须继承独立 T=0 阈值。若允许每个无序随机种子在同一批有限温数据里自由移动自己的 fc，再去优化 ψ / 坍缩，就可能人为抹掉样本间阈值差异。

3 · 从堆垛构型到最小滑移铁电相场

普通 φ⁴ 相场能教界面动力学，却容易把滑移铁电最重要的“周期性堆垛坐标”藏掉。一个更贴近本项目问题、但仍保持最小的教学模型，是把局域 stacking registry（堆垛配位） 压成周期变量 φ(r,t)，再把极化写成 φ 的周期函数。

P(φ)=P0 sinφ
F[φ]=∫d²r { κ/2 |∇φ|² + V0[1−cos(nφ)] − E P0sinφ + Fdis[φ,r] }
项保留的物理它没有自动包含什么
φ(r,t)局域有效相位 / 堆垛坐标完整原子坐标、多层所有堆垛标签
V₀[1−cos(nφ)]周期堆垛景观 / 多个等价极小值材料真实 DFT 能量面的所有各向异性
κ|∇φ|²/2空间平滑性、畴壁张力、有限畴壁宽度所有非局域弹性 / 静电作用
−EP₀sinφ电场驱动对有效极化的耦合微观非对角 BEC 张量本身
Fdis可控地测试耦合形式 / 关联 / 强度一个唯一、已知的真实缺陷的微观来源
建模边界：这个模型的价值是把 “周期堆垛 + 弥散畴壁 + 淬火无序 + 驱动” 放在同一最小框架里，用于比较机制与普适性。若结论依赖特定 3R 晶格方向、层间剪切张量、非对角 Born 有效电荷、多层界面耦合，就必须回到更细的自由度。
参数不是越多越真实：这个 periodic 模型写出 κ、V0、P0、Γ 与无序后，下一步不是一起拟合，而是先问哪些可观测量能独立约束哪些参数组合。去模块 07 看无量纲化 / 可辨识性 →

3.1 · 离散化不是纯数值细节

⟨h(r)h(r′)⟩=Δδ(d)(r−r′) ⇒ std(hcell)∝dx−d/2二维网格单元平均白噪声无序：std ∝ 1/dx。该缩放只针对明确的 δ 相关连续场约定。

因此 dx 收敛要固定的是 物理无序定义，不是数组每个像素的标准差。有限相关长度缺陷、固定位置缺陷、网格单元积分随机能量都必须重新从协方差 / 离散能量定义推导。

4.5 · 分析约定：在看结果前先写下哪些可调旋钮不能随意调

普适性项目最危险的自由度往往不在模拟器，而在分析脚本：fc、拟合区间、L 子集、粗糙度区间、等值线阈值、瞬态截断都可以把结果“调顺”。因此每个主可观测量至少要有主规则与敏感性检验。

可观测量主规则必须做的敏感性红灯
fc独立阈值 / 非稳态判据观测时长、判据、L同一有限温 / β 拟合里自由回调 fc
β预定约化驱动力区间族上下区间、fc 扰动、瞬态截断βeff 持续漂移
ζ预定畴壁提取 + 尺度掩膜等值线阈值、W/B/S(q)、去趋势悬垂比例高或局域/全局/谱指数分裂
完整验收链：模块 04 · UV/IR 尺度掩膜 → 有效斜率 → B/S/W → 异常标度/多重标度 → 样本层级不确定度
ν / 坍缩固定尺寸集合与目标函数逐一留出尺寸、端点 L 删除坍缩只靠一个 L 或一个自由参数支撑
完整验收链：模块 05 · 目标函数 → 逐一留出尺寸 → 留出尺寸 → 标度修正判据
z明确初态 / 瞬态可观测量时间区间、初态制备介观交叉区被当渐近
预注册不等于僵化。发现新交叉区后可以升级模型或新增次要分析，但要把它标成事后，并保留原主结果。这样“失效”才不会被分析自由度悄悄洗掉。

4.6 · 事件统计约定：不能因为把突发事件叫作“雪崩”就把它当成雪崩临界现象

固定事件检测器

主阈值、死时间 / 合并规则、带宽 / 采样率在看指数前固定；另外做一组事件检测器敏感性扫描。

固定事件大小定义

明确 S 是翻转面积、畴壁累计前进量、累计活动度还是电学脉冲面积；不同定义不能混在同一 τ 里。

保留层级结构

无序样本 → 事件 → 帧 / 时间箱 / 像素。自助法重采样只是计算工具，永远不是新的物理样本。

看到的现象允许的最低措辞升级前还缺什么
间歇峰突发 / 间歇翻转固定事件定义 + 事件检测器稳健性
宽事件大小分布宽分布 / 重尾事件幂律拟合优度 + 替代分布
候选幂律与幂律相容的区间截止 / 尺寸依赖 + 持续时间关系 + 无序样本稳健性
多个标度可观测量候选雪崩临界性临界控制参数 / 标度关系 / 适用时还要检查普适形状或标度函数
论文写作规则：“突发集中度” 或 “多重电阻跃迁” 可以是很有价值的现象学；在没有事件层级临界分析前，不把它们改名成 RFIM 雪崩。去模块 06 看完整统计边界 →

4.7 · 数据 → 估计量 → 证据 → 结论：先知道 n 在哪一层

一条研究结论不是从原始文件直接跳到论文表述。中间至少有四层：数据对象 是记录到的东西；估计量 把它压成一个可比较的量；证据单元 决定不确定度和独立样本数；最后才是 结论。最常见的伪精确，来自把这四层混在一起。

数据

轨迹、场记录行、帧、终点状态、事件、运行状态。

估计量

fc(i)、v、βeff、ζ、回线功、事件大小统计。

证据

哪些无序样本 / 器件 / 尺寸真正提供独立信息。

敏感性

区间、阈值、事件检测器、拓扑、观测时长改动后是否通过。

结论

从现象学到候选临界性，再到普适性。

4.7.2 · 阈值结果必须保留失败状态语义

运行 / 搜索状态允许进入的估计量正确解释
有效钉扎态 + 有效运动态上下界夹定单样本 fc(i) 区间 / 估计值在注册判据与观测时长下定位了阈值
有效钉扎态 up to Emax，仍未见运动态下界：fc(i) > Emax（在该方案下）右删失 / 受观测时长限制，不是无限阈值
观测时间不足以区分 late 运动未解析 / 删失状态缺少观测时长，不应硬塞进钉扎态或运动态
求解器 / 数值证明 / 数值质量检查失败不进入物理阈值估计量数值无效 ≠ 物理钉扎态
绝不做的事：把未解析样本删掉直到图变漂亮；把未完成上下界夹定的样本随便赋成 Emax；或者把数值失败解释成“墙被钉住”。这些都会直接偏置总体 fc 与后续 β。

目标上游依据当前层只允许调什么红灯
β独立 T=0 阈值依据预注册的约化驱动力 / 瞬态区间族为了让 β 更直而回调 fc
ζ通过拓扑 / 单值性判据的畴壁 extraction预注册尺度掩膜 + 等值线敏感性只挑 W、B、S(q) 中最漂亮的一种
ν / 坍缩多 L 阈值 / 速度估计值固定目标函数 + 逐一留出尺寸敏感性每次坍缩都重新自由挑 L 和 fc
热圆滑冻结的 T=0 fc / fc(i)热随机种子、T 区间、圆滑可观测量用有限温曲线事后重定阈值
雪崩统计冻结的事件检测器 / size 定义截止、替代分布检验、形状检验看到指数后再改合并 / 死时间规则
这叫依据链：下游分析可以对上游不确定度做敏感性传播，但不能把上游估计量当成隐藏自由参数重新优化。否则同一批数据会被多次“用来证明自己”。

4.7.4 · 结论阶梯：失败时知道该退到哪一级

证据层级最低要求允许的写法
E0 · 原始数据完整性来源追踪、配置、状态、单位、重复/别名检查数据集 / 运行集合可审计
E1 · 估计量稳定性判据 / 区间 / 事件检测器 / extraction 敏感性稳健类阈值 / 形貌 / 动力学可观测量
E2 · 总体 / 尺寸证据正确独立单元、删失处理、多无序样本 / L总体区分 / 有限尺寸趋势 / 有效指数
E3 · 跨可观测量临界证据fc、β、ζ、ν/z 中多个独立可观测量相互兼容候选退钉扎临界区间
E4 · 普适性 / 失效标度关系、坍缩、拓扑判据、修正与替代解释一起通过候选普适类；或明确映射失效
失效不是“没做成”。 如果 β/ζ/ν 无法在同一依据链下相容，或拓扑判据系统失败，正确结果可能就是：该滑移铁电区间只能称为类退钉扎 / 有效界面交叉区，而不是强行给它套普适性标签。
公开边界：这里给的是可复用的分析约定，不展示项目未发表数值、内部批次标签或当前判据状态。真正分析时再把每个数据集映射到这张表。上游每个模拟运行还必须能回答“它到底由哪版代码、哪份最终生效配置、哪组随机源与哪种停止状态生成”；去模块 07 看运行记录 / 来源追踪约定 →

4.8 · 配对与分层不确定度：同一来源内做差，跨来源才谈总体

“匹配比较” 不只是在横轴上把两个参数调到同一个数。若 A/B 两个耦合能由同一个预先定义的潜在来源生成，配对设计 可以先消掉无序样本之间的大波动，再问耦合形式本身改变了多少。但配对是实验设计，不是事后统计技巧：必须在看结果前定义，而且不能跨本来就不可交换的证据层级强行配对。

Δi = yA,i − yB,i　；　Δ̄ = N−1 Σi=1N Δi

这里真正进入总体推断的基本对象是独立来源 i 的配对差值 Δi，不是 A/B 两边所有时间序列行的总和。

4.8.1 · 配对什么时候是公平的？

相同干扰来源

两条条件共享的是你想消掉的干扰波动，例如同一独立无序来源 / 器件，而不是为了让结果相似才事后挑最接近的配对。

固定映射

从潜在来源到 A/B 无序样本的变换必须预先定义，并保持各自目标边缘分布 / 匹配约定；“同随机种子”本身不自动等于公平。

相同证据层级

生产数据、留出数据、后继数据、历史数据或不同方案若依据不同，就不能只因为能找到共同标签而塞进一张配对表。

共同随机数是方差降低工具，不是物理等价证明。 配对能让来源内差值更精确，但不能抹掉 A/B 耦合的不同数学结构，也不能替代公平的物理匹配。

4.8.2 · 外层样本与内层重复要分开

层级典型对象主要用途不确定度怎么处理
外层独立单元独立无序样本 / 独立器件总体推断CI / 自助法 / 模型的最外层重采样单元
配对条件同一来源下 A 与 B 耦合 / 方案来源内差值先在来源内形成 Δi，再跨 i 汇总
内层随机重复固定淬火景观下的热随机种子估计条件热平均 / 随机波动先在 i 内平均或做分层模型；不能冒充新无序样本
重复观测时间序列行、循环、帧、事件估计轨迹 / 事件分布 / 形貌保留聚类结构；不能用数据行数放大总体 n
自助法 draw重采样索引集合传播估计量不确定度重采样次数只控制蒙特卡洛精度，不增加物理样本

4.8.3 · 有限温：先在淬火无序样本内平均，再跨来源推断

ȳi,c = Mi,c−1 Σj yi,c,j　；　Δi = ȳi,A − ȳi,B

其中 i 是 quenched 无序样本，j 是热随机种子，c 是条件。若研究问题是“平均热响应在不同耦合间是否不同”，最简单的依据是先得到每个 i,c 的条件估计量，再对 Δi 做外层层级推断。若内层随机方差本身也是科学问题，可用分层 / nested 自助法，但外层独立单位仍然是 i。

不要把更多热随机种子当成更多无序。 增加内层重复会降低给定景观下热均值的蒙特卡洛噪声，却不能凭空增加对无序总体的覆盖。

4.8.4 · 缺失 / 删失配对不能靠“补一个数”恢复完整

情况错误处理正确方向
A 有有效估计，B 只有下界把 B=Emax 后直接算 Δ保留配对删失 / bound 信息；若主估计量不支持，降级为部分信息分析
A 数值无效，B 有效把 A 当钉扎态或从配对样本静默删除记录失配原因；区分技术性缺失机制与物理删失
某来源只有一侧通过拓扑判据只保留“好看”的另一侧几何指数该配对几何差值不成立；保留失效 / 缺失机制本身
多个结果同时显著把每个差值当独立发现预定义主族，必要时多重比较控制；同时报告效应量 / 置信区间

4.8.5 · 有限尺寸也有配对陷阱

为了降噪，有时会让不同 L 使用相关的无序构造，例如从同一个大场裁剪 / 限制出较小系统。这样做不是禁止的，但会让不同 L 的估计量相关；此时“每个 L 一点”不能被当成互相独立的样本。若目标是最简单透明的有限尺寸推断，优先让每个 L 有独立无序样本；若有意使用共同随机数 / 嵌套尺寸设计，就把相关结构写进记录和统计模型。

最实用的统计顺序：先决定独立单元 → 再决定哪些条件在单元内配对 → 再处理热/事件/cycle 等内层重复 → 最后才选择自助法 / 分层模型。反过来先把 CSV 全部堆进统计包，几乎一定会把 n 算错。
这节与 数据 → 估计量 → 证据 → 结论 是同一件事的统计版本；而每个外层 / 内层身份怎样被保存，则回到 模块 07 的运行记录。

5 · 机制证伪：先排掉简单解释，再谈“真正机制”

研究型阅读与普通教材最大的区别之一：数据往往更擅长否定一个过于简单的机制，而不是直接唯一确定微观机制。

假说 A：无序只增加一个统一延迟

预期：不同强度下时间排序应保持同一方向，主要只是整体变慢/变快。

若排序随强度 / 翻转阶段改变：可以排除一个与强度无关标量延迟图像；但还不能因此命名唯一新机制。

假说 B：某种耦合永远“更碎”

预期：分量数量、界面密度、最大分量比例应给出跨 stage 一致的碎裂排序。

若不同形貌指标不给统一排序：应放弃单一碎裂图像，转向阶段依赖路径。

最重要的研究纪律：“简单机制被证伪”本身就是结果。不要为了让故事看起来更完整，立即用另一个没有被独立测量的机制填空。

6 · 这条研究路线最终怎样接回 8 个模块？

03

先判断真正运动对象：畴壁、协同滑移，还是条件依赖的多种路径。

04 / 06
