从“会 switch”走到“为什么这样 switch”

这不是第 9 个基础模块，也不是未发表结果展示页。它把 03–07 已经学过的材料机制、pinning、depinning、disorder 与 phase-field 压成一条真正可执行的研究链：如何公平比较不同 disorder coupling？什么时候 hysteresis 问题必须换成 isolated-wall experiment？每个 observable 到底允许你 claim 什么？

中心问题：传统 ferroic driven-interface framework 在 sliding ferroelectricity 中能走多远？ 目标不是预设“必然 universal”，而是同时设计 survives 与 breaks down 两种结果都能被识别的实验。

1 · Disorder is not one number：σ 之前先问“随机了什么”

传统铁电已经给出一个很强的提醒：disorder 不是只用一个幅度参数描述。Jesse et al. 2008 从正、负 local nucleation bias 中分别重建 disorder potential 的 random-field 与 random-bond components；Ovchinnikov et al. 2009 又进一步说明 hysteresis shape 本身携带 disorder type 与 strength 的信息。对 sliding FE 来说，更不能先把所有 defect 压成“一个 σ”，再讨论谁更强。

Coupling type

disorder 是直接偏爱某个 local state，还是改 barrier / stiffness / mobility / geometry？

Strength

RMS、energy variance、local force RMS 等不同定义并不自动等价。

Correlation length

white disorder 与 finite-size defects 即使 RMS 相同，也可能产生不同 collective dynamics。

experimental anchorJesse et al., Nature Materials 7, 209–215 (2008)

作者直接从 local nucleation biases 提取 random-bond 与 random-field disorder components。DOI 10.1038/nmat2114

inference anchorOvchinnikov et al., PRL 103, 157203 (2009)

在 random-bond–random-field Ising framework 中，用 hysteresis loop shape 识别 disorder type / strength；它证明“loop shape 含 disorder 信息”，但不意味着真实 sliding FE 自动服从同一 Ising model。DOI 10.1103/PhysRevLett.103.157203

因此真正公平的问题不是“RF 的 σ 和 RB 的 σ 谁大”，而是：在明确的 matching rule 下，改变 coupling law 本身是否仍改变 switching？

1.1 · 一个适合 sliding-FE 的有效比较语言

Additive random-field-like coupling
FRF = −h(r) cos[φ−α(r)]

local generalized force / torque：
τRF ∝ −h sin(φ−α)。它可以直接偏置 local phase coordinate。

Barrier-amplitude / random-bond-like coupling
FRB = δV(r)[1−cos(nφ)]

local generalized force / torque：
τRB ∝ −nδV sin(nφ)。它主要修改 periodic landscape 的 barrier / curvature。

术语纪律：这里的 “random-field-like / random-bond-like” 指 continuum effective coupling。它不等于说模型已经变成 RFIM，也不意味着真实 defect 只有这两种 microscopic origin。
matching rule优点局限
same parameter std代码最简单不同 coupling function 下通常没有明确“等强”物理意义
same energy variance比较 energy landscape fluctuation动力学由 derivative / force 决定时仍可能不公平
same phase-averaged local-force RMS直接对齐 driving equation 里 disorder force scale依赖选定 phase measure；不能抹掉 coupling form 的差异

最后一种尤其适合回答“把局域 force scale 对齐以后，coupling law 还重要吗？”——但 matching 是控制变量，不是理论上保证两个 disorder 动力学等价的变换。

1.2 · 为什么这在真实 sliding FE 里不是纯数学游戏

2026 年 CVD-grown 3R-WSe₂ 工作明确报告：growth-induced structural disorder 会显著影响 polarization switching，且 multi-domain kinetics 控制 FE response 的演化。这类实验告诉我们“disorder matters”，但从 structural disorder 到 RF / RB / mobility / geometry disorder 的 coarse-graining 仍需逐项论证。

2 · Full switching 与 isolated-wall depinning：不是同一套实验换个名字

这是 Research Track 最重要的 protocol split。Triangle-wave hysteresis 很适合研究完整 switching system；但如果问题变成“一个预先存在的 wall 是否存在 critical depinning”，就必须尽量把 nucleation、multi-domain pathway 与 history 混合因素拿掉。

2.5 · Temperature 是新的实验轴，不是把 random seed 多跑几次

当 isolated-wall T=0 protocol 稳定以后，有限温度自然分成两个不同的问题：

Deep subcritical · creep

f<fc 且离阈值足够远：问 thermally activated barriers 是否产生可测的长期 drift，是否存在稳定 creep window 与 μ candidate。

Near threshold · thermal rounding

f≈fc：问 T=0 singularity 怎样被温度圆滑，是否存在 v(fc,T)∼Tψ 与 joint field–temperature scaling。

层次应该固定什么重复什么独立统计单元
quenched disorder一个 landscape h(r)/δV(r)换 disorder seed用于 disorder population inference 的 outer block
thermal noise同一个 quenched landscape换 Langevin/noise seed同一 landscape 内的 conditional repeat
trajectory frames同一次 run随时间采样不是新的 disorder sample
最重要的 anti-overfit rule：thermal rounding 必须继承独立 T=0 threshold。若允许每个 disorder seed 在同一批 finite-T 数据里自由移动自己的 fc，再去优化 ψ / collapse，就可能人为抹掉 sample-to-sample threshold variation。

3 · 从 stacking registry 到 minimal sliding-FE phase field

普通 φ⁴ phase field 能教 interface dynamics，却容易把 sliding FE 最重要的“周期性 stacking coordinate”藏掉。一个更贴近本项目问题、但仍保持 minimal 的教学模型，是把 local registry 压成周期变量 φ(r,t)，再把 polarization 写成 φ 的周期函数。

P(φ)=P0 sinφ

3.1 · discretization 不是纯数值细节

⟨h(r)h(r′)⟩=Δδ(d)(r−r′) ⇒ std(hcell)∝dx−d/2二维 cell-average white disorder：std ∝ 1/dx。该缩放只针对明确的 δ-correlated continuum-field convention。

因此 dx convergence 要固定的是 physical disorder definition，不是数组每个 pixel 的 std。有限相关长度 defects、固定位置 defects、cell-integrated random energy 都必须重新从 covariance / discrete energy 定义推导。

4.7 · Data → Estimator → Evidence → Claim：先知道 n 在哪一层

一条研究结论不是从 raw file 直接跳到 paper sentence。中间至少有四层：data object 是记录到的东西；estimator 把它压成一个可比较的量；evidence unit 决定不确定度和独立样本数；最后才是 claim。最常见的伪精确，来自把这四层混在一起。

Data

trajectory、field row、frame、endpoint、event、run status。

Estimator

fc(i)、v、βeff、ζ、work、event-size statistics。

Evidence

哪些 realization / device / size 真正提供独立信息。

Sensitivity

window、threshold、detector、topology、exposure 改动后是否 survive。

Claim

从 phenomenology 到 candidate criticality，再到 universality。

层级规则：trajectory rows、cycles、frames、pixels、events、endpoints 与 bootstrap draws 都可能非常多，但是否能进入独立 n 取决于生成它们的随机化层级。先画出 realization → run/condition → repeated observation 的树，再决定 CI / test / bootstrap 怎么做。

4.8 · Pairing & hierarchical uncertainty：同一 source 内做差，跨 source 才谈 population

“matched comparison” 不只是在横轴上把两个参数调到同一个数。若 A/B 两个 coupling 能由同一个预先定义的 latent source 生成，paired design 可以先消掉 realization-to-realization 的大波动，再问 coupling law 本身改变了多少。但 pairing 是实验设计，不是事后统计技巧：必须在看 outcome 前定义，而且不能跨本来就不可交换的 evidence strata 强行配对。

Δi = yA,i − yB,i　；　Δ̄ = N−1 Σi=1N Δi

这里真正进入 population inference 的基本对象是独立 source i 的 paired contrast Δi，不是 A/B 两边所有 time rows 的总和。

4.8.1 · pairing 什么时候是公平的？

Same nuisance source

两条 condition 共享的是你想消掉的 nuisance variation，例如同一独立 disorder source / device，而不是为了让结果相似才事后挑最接近的 pair。

Frozen mapping

从 latent source 到 A/B disorder realization 的变换必须预先定义，并保持各自目标 marginal distribution / matching contract；“同 seed”本身不自动等于公平。

Same evidence stratum

production、holdout、successor、legacy 或不同 protocol 若 authority 不同，就不能只因为能找到共同标签而塞进一张 paired table。

common random numbers 是 variance-reduction device，不是物理等价证明。 pairing 能让 within-source contrast 更精确，但不能抹掉 A/B coupling 的不同数学结构，也不能替代 fair physical matching。

4.8.2 · outer sample 与 inner repeat 要分开

层级典型对象主要用途不确定度怎么处理
outer independent unit独立 disorder realization / independent devicepopulation inferenceCI / bootstrap / model 的最外层 resampling unit
paired condition同一 source 下 A vs B coupling / protocolwithin-source contrast先在 source 内形成 Δi，再跨 i 汇总
inner stochastic repeat固定 quenched landscape 下的 thermal seeds估计 conditional thermal expectation / stochastic spread先在 i 内平均或做 nested model；不能冒充新 disorder samples
repeated observationtime rows、cycles、frames、events估计 trajectory / event distribution / morphology保留 clustering；不能用 row count 放大 population n
bootstrap drawresampled index sets传播 estimator uncertaintydraw 数量只控制 Monte Carlo precision，不增加物理样本

4.8.3 · finite-T：先在 quenched source 内平均，再跨 source 推断

ȳi,c = Mi,c−1 Σj yi,c,j　；　Δi = ȳi,A − ȳi,B

其中 i 是 quenched realization，j 是 thermal seed，c 是 condition。若研究问题是“平均 thermal response 在不同 coupling 间是否不同”，最简单的 authority 是先得到每个 i,c 的 conditional estimator，再对 Δi 做 outer-level inference。若 inner stochastic variance 本身也是科学问题，可用 hierarchical / nested bootstrap，但外层独立单位仍然是 i。

不要把更多 thermal seeds 当成更多 disorder。 增加 inner repeats 会降低给定 landscape 下 thermal mean 的 Monte Carlo noise，却不能凭空增加对 disorder population 的覆盖。

4.8.4 · missing / censored pair 不能靠“补一个数”恢复完整

情况错误处理正确方向
A 有 valid estimate，B 只有 lower bound把 B=Emax 后直接算 Δ保留 paired censoring / bound 信息；若主 estimator 不支持，降级为 partial-information analysis
A numerical-invalid，B valid把 A 当 pinned 或从 paired sample 静默删除记录失配原因；区分 technical missingness 与 physical censoring
某 source 只有一侧通过 topology gate只保留“好看”的另一侧 geometry exponent该 paired geometry contrast 不成立；保留 breakdown / missingness 本身
多个 outcomes 同时显著把每个 contrast 当独立发现预定义 primary family，必要时 multiplicity control；同时报告 effect / CI

4.8.5 · finite-size 也有 pairing 陷阱

为了降噪，有时会让不同 L 使用相关的 disorder construction，例如从同一个大 field crop / restrict 出较小系统。这样做不是禁止的，但会让不同 L 的 estimator 相关；此时“每个 L 一点”不能被当成互相独立的样本。若目标是最简单透明的 finite-size inference，优先让每个 L 有独立 disorder realizations；若有意使用 common-random-number / nested-size design，就把 correlation structure 写进 receipt 和统计模型。

最实用的统计顺序：先决定 independent unit → 再决定哪些 condition 在 unit 内 paired → 再处理 thermal/event/cycle 等 inner repeats → 最后才选择 bootstrap / hierarchical model。反过来先把 CSV 全部堆进统计包，几乎一定会把 n 算错。
这节与 Data → Estimator → Evidence → Claim 是同一件事的统计版本；而每个 outer / inner 身份怎样被保存，则回到 Module 07 的 run receipt。

5 · Mechanism falsification：先排掉简单解释，再谈“真正机制”

研究型阅读与普通教材最大的区别之一：数据往往更擅长否定一个过于简单的机制，而不是直接唯一确定微观机制。

假说 A：disorder 只增加一个统一 delay

预期：不同 strength 下 temporal ordering 应保持同一方向，主要只是整体变慢/变快。

若 ordering 随 strength / switching stage 改变：可以排除一个 intensity-independent scalar-delay picture；但还不能因此命名唯一新机制。

假说 B：某种 coupling 永远“更碎”

预期：component count、interface density、largest-component fraction 应给出跨 stage 一致的 fragmentation ordering。

若不同 morphology metrics 不给统一 ordering：应放弃单一 fragmentation cartoon，转向 stage-dependent pathway。

最重要的研究纪律：“simple mechanism 被 falsify”本身就是结果。不要为了让故事看起来更完整，立即用另一个没有被独立测量的 mechanism 填空。
