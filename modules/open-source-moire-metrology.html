moire_metrology

先看整条因果链

twist / mismatch→local stacking registry→u(r)→elastic cost+GSFE→energy minimization→relaxed domains / walls / strain
[项目文档支持]docs/theory.md 明确写出总能量为 E = E_elastic + E_GSFE，并把 u(r) 定义为面内位移场；README 将仓库定位为 twisted 2D van der Waals heterostructures 的 atomic relaxation、strain extraction 和 multilayer analysis。
读库原则：先暂时忘掉自己的 φ。先把作者为什么需要二维位移矢量、为什么 GSFE 是二维周期面、为什么 elastic 和 interface 参数必须分开弄懂。

Level 1 · Physical question（物理问题）

两层二维晶体发生小角度扭转或晶格失配后，每个位置的 local registry（局域堆垛注册关系）不同。体系一方面想局部落到更低的 stacking-energy minimum（堆垛能极小值），另一方面层内形变要付 elastic energy（弹性能）。真正的问题是：这两种代价竞争后，空间中的位移、畴和畴壁会怎样重构？

为什么不是一个局域变量就够

局域堆垛由两层晶格之间的二维相对平移决定，因此 natural degree of freedom（自然自由度）是二维 u=(ux,uy)，而不是先验的一维标量。

为什么要 continuum

moiré wavelength（莫尔周期）可以远大于原子尺度。连续位移场保留长波弹性和 registry-dependent interaction（堆垛依赖相互作用），避免逐原子模拟整个大超胞。

[论文 / 项目文档支持]仓库将 single-interface relaxation 对应到 Halbertal et al., Nature Communications 12, 242 (2021)，multilayer relaxation 对应到 PRX 13, 011026 (2023)。这些论文是代码方法链的直接来源，而不是后来附会的背景阅读。

Level 2 · Model construction（模型构造）

这一层最值得学的是：作者不是先选一个“好算的势”，而是先确定自由度，再用 symmetry（对称性）限制 GSFE 的函数形式，用 elasticity（弹性）限制空间变化。

2.1 基本自由度：displacement field（位移场）

u(r) = (uₓ(r), uᵧ(r))

每层被视为二维弹性薄片。u 的空间梯度给 strain（应变）；两层位移差加上未弛豫的 moiré phase（莫尔相位）给 local stacking phase（局域堆垛相位）。

[源码直接支持]energy.py · RelaxationEnergy 在构造时先计算未弛豫 stacking phases self._v0, self._w0 = geometry.stacking_phases(x, y)，随后把各层位移自由度组合进 GSFE-coupled pairs。

2.2 总自由能：层内弹性 + 层间堆垛

E[u] = Eelastic[u] + EGSFE[u]
Eelastic = ½K(∂ₓuₓ+∂ᵧuᵧ)² + ½G[(∂ₓuₓ−∂ᵧuᵧ)² + (∂ₓuᵧ+∂ᵧuₓ)²]

这里的 K 和 G 不是为了“平滑图”加的数值正则项；它们是二维材料的 bulk modulus（体模量）和 shear modulus（剪切模量）。这意味着 gradient-like cost（梯度型代价）有明确的 elasticity origin（弹性来源）。

[合理物理解释]这与很多标量 phase-field model（相场模型）中的 κ|∇φ|²/2 在数学角色上相似：都惩罚空间快速变化；但这里系数直接来自二维弹性张量的简化，而不是一开始就压成单个 κ。

2.3 GSFE 不是单个 cosine，而是 symmetry-constrained Fourier surface（对称性约束的傅里叶能量面）

V(v,w)=c₀+c₁[cos v+cos w+cos(v+w)] + c₂[...] + c₃[...] + c₄[sin v+sin w−sin(v+w)] + c₅[...]

这里 v,w 是 stacking phase coordinates（堆垛相位坐标）。六个系数不是六个随意的拟合按钮：基函数本身编码 hexagonal lattice symmetry（六角晶格对称性），而 inversion symmetry（反演对称性）进一步限制某些项。

[源码直接支持]gsfe.py · GSFESurface.__call__ · lines 37+ 直接实现这套六系数 Fourier expansion。docs/theory.md 明确说明 centrosymmetric homobilayers（中心对称同质双层）有 c4=c5=0；broken-inversion heterointerfaces（破缺反演的异质界面）允许非零 sine terms（正弦项）。
[论文直接支持]interfaces.py 对 graphene、hBN、MoSe₂/WSe₂ 等 GSFE 系数逐项附带 Carr、Zhou、Shabani/Halbertal 等来源，并在需要时做 Fourier basis / unit conversion（傅里叶基底 / 单位转换）。

Deep dive · real space 怎样变成 stacking phase

这是理解整个仓库最关键的一步：GSFE 的自变量不是实验室坐标 x,y，而是“两个晶格在这个位置相对错开了多少”的 phase coordinates（相位坐标）v,w。lattice.py 负责把真实空间、扭转、失配和位移统一变成这两个变量。

G1 · 单层晶格：real space → reciprocal phase

B = a[b₁ | b₂] ;　M = (2π/a)[b₁ | b₂]⁻¹ ;　M B = 2π I

HexagonalLattice.reciprocal_matrix 构造 M，因此沿任一 primitive lattice vector（原胞基矢）移动一次，phase 正好增加 2π。这不是“方便画周期图”的技巧，而是在数学上把真实空间平移转成周期 GSFE 的自然角变量。

[源码直接支持]lattice.py · HexagonalLattice.reciprocal_matrix 明确写出 [v;w]=M@[x;y]；tests/test_lattice.py::test_reciprocal_matrix_orthogonality 检查 M @ B = 2πI 到数值精度。

G2 · 两层不完全重合：moire matrix（莫尔矩阵）

Mr = R(+θ) − (I + ε)
[V₁ | V₂] = Mr−1 B

这里 θ 描述 relative twist（相对扭转），ε 描述 lattice mismatch / heterostrain（晶格失配 / 异质应变）。莫尔基矢 V₁,V₂ 就是让两层相对 phase 再次走完整周期的长尺度基矢。

[源码直接支持]MoireGeometry.moire_matrix / moire_vectors 直接实现上式；代码注释特别强调使用 R(+θ) 是为了让跨越 V₁/V₂ 时 stacking phase 精确跳过整数个 2π，从而 GSFE 在周期边界上无缝拼接。
[源码直接支持]tests/test_lattice.py::test_wavelength_formula 验证 matched lattice 时 λ≈a/[2sin(θ/2)]；test_lattice_mismatch_wavelength 验证零扭角、纯 mismatch 时 λ≈a/δ；这说明 geometry 层不是只“看起来像 moiré”，而是先锁住已知解析极限。

G3 · relaxation 真正怎样改变 stacking

phase(r,u) = Mu1[r − u(r)] − Mu2 r
Mu1 = M R(−θ)T ;　Mu2 = (I+ε)M

如果上层在某点发生 displacement（位移）u(r)，代码不是“把 u 加进能量里”这么模糊，而是先用 Mu1 把它转换成 local stacking phase shift（局域堆垛相位变化），再把新的 v,w 送进 GSFE surface。于是链条是：

u(r)→Δv(r), Δw(r)→V[v(r),w(r)]→local force = −∂V/∂u
pos = np.stack([x, y], axis=0)

shifted = pos - disp
phase_twisted = self.Mu1 @ shifted
phase_substrate = self.Mu2 @ pos

phase = phase_twisted - phase_substrate
return phase[0], phase[1]
逐行读法
  1. pos 是实验室真实空间坐标。
  2. pos-disp 把上层原子/连续片层的局域平移写入几何。
  3. 两层分别映射到 phase space（相位空间）。
  4. 相减才得到“相对堆垛”，也就是 GSFE 真正关心的量。
[推导]这一结构说明“能量面 V”和“空间场 u(r)”不是同一个对象：V 定义在 stacking space（堆垛空间），u 定义在 real space（真实空间）。模型的核心工作正是用晶格几何把两者连接起来。

G4 · 为什么需要 mesh / FEM，而不是直接二维数组

MoireMesh.generate 用 V₁,V₂ 构造周期平行四边形，并做 periodic triangulation（周期三角剖分）；Discretization 在每个三角形上构造线性 shape-function gradient（形函数梯度），把 ∂u/∂x、∂u/∂y 变成稀疏矩阵运算。

[源码直接支持]mesh.py · MoireMesh.generate 令 r=sV1+tV2 并在边界索引上周期 wrap；discretization.py · _build_diff_matrices 用三角形线性形函数组装微分矩阵。tests/test_discretization.py 分别检查常数场导数为 0、线性场导数为 1、周期正弦场导数以及总网格面积。
这一节学到的核心：continuum model 的“物理坐标 → 内部相位坐标 → 能量面”映射必须明确。以后看到任何把一维 φ 直接塞进周期势的模型，都应该先问：φ 到底是哪一个真实构型坐标的参数化？

Level 3 · Parameter origin（参数来源）

这一库最值得模仿的工程习惯之一，是把“单层材料参数”和“界面参数”分成不同对象，并让文献来源跟着参数走。

参数物理角色代码位置来源类型学习重点
alattice constant（晶格常数）materials.py · Material[文献 / 材料数据]决定 moiré geometry 与 unit-cell area。
K, G2D bulk / shear modulus（二维体 / 剪切模量）materials.py[论文直接支持]Graphene 引 Carr；hBN 由实验 Young's modulus + Poisson ratio 推导；TMD 值来自 Halbertal/Shabani。

Material ≠ Interface

Material 只保存 lattice constant、K、G；registry-dependent GSFE 被放进 Interface。这避免“MoSe₂ 自己有一张 MoSe₂/WSe₂ GSFE”这种概念错误。

单位也属于模型

仓库统一使用 meV per unit cell，并提供 N/m ↔ meV/uc 转换。参数单位转换不是外围杂事，而是防止模型悄悄错量纲的一部分。

[源码直接支持]materials.py 文档把 graphene 的 K/G 追到 Carr et al.，并给出与实验 N/m 的 sanity check（合理性核对）；custom-materials.md 还明确提醒新材料必须检查 Fourier basis、per-cell/per-area 单位以及 stacking convention。
[尚未验证]本页没有自行断言上游每个 bundled coefficient 都是“原始 DFT 数值”。代码自身区分了来自 DFT parameterization、实验弹性数据、文献转换和派生值；后续如要做逐参数审计，还需逐篇核原始表格。

4.1 公式怎样变成 GSFE 代码

def __call__(self, v, w):
    c0,c1,c2,c3,c4,c5 = self.c
    return (
        c0
        + c1*(cos(v)+cos(w)+cos(v+w))
        + c2*(cos(v+2*w)+cos(v-w)+cos(2*v+w))
        + c3*(cos(2*v)+cos(2*w)+cos(2*v+2*w))
        + c4*(sin(v)+sin(w)-sin(v+w))
        + c5*(sin(2*v+2*w)-sin(2*v)-sin(2*w))
    )
逐行读法
  1. self.c 不是运行时随机参数，而是某个具体 interface 的六个 Fourier coefficients。
  2. 三组 cosine combinations 保持六角晶格允许的周期结构。
  3. sine combinations 让 broken inversion symmetry 可以进入 landscape。
  4. 输出只是局域 stacking energy；空间耦合仍由 elasticity 那部分负责。
[源码直接支持]摘录对应 frozen commit 的 src/moire_metrology/gsfe.py::GSFESurface.__call__。完整实现还提供一阶、二阶解析导数，用于 gradient / Hessian 计算。

4.2 局域 registry 怎样接到空间位移场

x, y = disc.mesh.points[0], disc.mesh.points[1]
self._v0, self._w0 = geometry.stacking_phases(x, y)

self._Mu1 = geometry.Mu1
self._area_v_norm = disc.vertex_areas / Suc
self._Dx = disc.diff_mat_x
self._Dy = disc.diff_mat_y
逐行读法
  1. 先在每个 mesh vertex（网格顶点）计算未弛豫的 stacking phase。
  2. Mu1 负责 displacement → stacking-phase coordinates 的转换。
  3. area weights 把离散顶点/三角形和连续能量积分连接起来。
  4. Dx/Dy 是位移梯度进入 elastic energy 的离散算子。

4.3 solver 不是一个“万能最小化按钮”

SolverConfig 同时提供 trust-region Newton-CG、modified Newton、pseudo-dynamics、L-BFGS-B 和 two-phase 路径。文档甚至明确讨论不同 solver 在 multi-basin landscape（多盆地能量景观）里的 basin-selection bias（盆地选择偏置）。

[源码直接支持]solver.py 说明 modified Newton 会翻转 GSFE Hessian 的负特征值，因此不能沿负曲率穿越 saddle（鞍点）；trust-ncg 保留真实负曲率；L-BFGS-B 可落入不同 basin。这里“求解算法会影响找到哪个亚稳态”被当成模型可信度问题，而不是单纯性能问题。
physical assumption→E[u]→GSFE + elastic derivatives→optimizer / gradient flow→RelaxationResult→stacking / elastic-energy / twist maps

Validation（验证）与 numerical credibility（数值可信度）

多重收敛判据

gtol 看绝对 gradient norm；rtol 看相对下降；etol 看能量是否停滞。低 twist 时大体系总能量会让单一绝对阈值失真，因此作者没有只押一个判据。

多个 solver 交叉检查

当 landscape 有多个 basin，算法本身可能决定落在哪个 stationary state（驻态）。保留不同求解器是一种机制/数值敏感性检查。

单位 sanity check

Material 支持把内部 meV/uc 转回 N/m，与实验/文献常用单位核对，避免“代码数字正确但物理单位错”。

方法链对应论文

docs/references 不是泛泛的 bibliography，而是把 single-interface、multilayer、strain extraction、point-pinning 分别对应到具体论文。

[合理物理解释]这个项目的 validation culture（验证文化）给出的一个重要 taste：复杂模型不是靠“项更多”变可信，而是靠 provenance（来源）、units（单位）、solver sensitivity（求解器敏感性）和与已知实验/论文结果的闭环变可信。

Modeling Taste（建模方法论）

  • 先选物理自由度，再选函数形式。局域 registry 天然是二维平移，所以从 u=(uₓ,uᵧ) 出发。
  • 用 symmetry 缩小函数空间。GSFE 不是任意神经网络曲面，也不是单个 cosine；先规定晶格允许的 Fourier basis，再让少量 coefficient 承担材料信息。
  • 把 material property 和 interface property 分开。这是一种物理概念边界，也是一种软件边界。
  • 参数 provenance 跟着数据走。代码里直接留下 reference，而不是在论文 Methods 里另放一份难以对应的参数表。
  • numerical choice 不伪装成 physics。pixel_size、gtol、solver method 与 K/G、GSFE coefficients 是不同类别。
  • 承认 energy landscape 有多个 basin。求解器不是“找到真答案”的中性黑盒；不同算法能否跨 saddle 会改变找到的驻态。
  • 简化要能说出丢掉了什么。isotropic linear elasticity 是简化，但仓库甚至保留 nonlinear elasticity 等扩展入口；简化有明确边界。

Exercises（练习）

练习 1 · symmetry

把 c4=c5=0 和 c4,c5≠0 的两个 GSFE surface 各画一次。只看 symmetry breaking 后极小值、鞍点和路径不对称性怎么变。

练习 2 · projection

取一条二维路径 u(s)，计算 V[s] 并用 1、2、3 阶 Fourier harmonic（傅里叶谐波）拟合。记录 barrier height 和 saddle position 的误差。

练习 3 · parameter category

从一个 example 的配置中，把所有数值分成 physical material parameter、interface parameter、geometry、numerical tolerance 四类。

练习 4 · solver sensitivity

理解为什么 multi-basin landscape 下“两个 solver 收敛”不意味着“它们一定收敛到同一个物理解”。先解释，再考虑是否需要实际运行。
