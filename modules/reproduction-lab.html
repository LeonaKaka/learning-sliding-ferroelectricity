先别复现整篇论文：先证明你的 TDGL 真的会长出“正确的墙”

主论文：Caballero et al., PRB 102, 104204 (2020)。这节不直接挑战作者的大尺寸 2D GL ↔ elastic-line 结果，而先抽出一个可解析、普通 CPU 很快就能验收的 gold test：数值 domain wall 必须收敛到论文 Eq. (7–8) 的 tanh kink。

唯一目标：不相信“看起来差不多”。解析解自己来验代码。
profile RMSE、wall width、free-energy descent 三关都过，才允许进入 2D wall。

0 · 这节到底复现论文的哪一块？

Caballero 的 bulk level 使用非守恒标量 order parameter φ(r,t)、双井 φ⁴ potential 和 overdamped Langevin / Model-A dynamics；clean case 的 stationary soliton 给出一堵解析可知的 domain wall。项目权威来源是 Drive 中的 Caballero et al. 2020 PDF；期刊版本：PRB 102, 104204。

V(φ)=−αφ²/2+δφ⁴/4　；　η∂tφ=γ∇²φ−V′(φ)+h+ξ
φ*(x)=−φ₀ tanh(x/w),　φ₀=√(α/δ),　w=√(2γ/α)本课只取 h=0、T=0 的 clean 1D validation unit。
不是“复现论文 Fig. 1”。这是从同一模型和解析结果抽出的最小 validation unit。它先检查离散化、边界条件和 TDGL 更新；roughness / structure factor 后面再复现。

1 · 为什么故意从一个错误的 wall 开始？

不能直接初始化答案

如果一开始就填 analytic tanh，代码“不动”并不能证明 integrator 正确。

故意设成 3w

初始 wall 比 equilibrium wall 宽三倍，强迫 TDGL 真正发生 relaxation。

看它自己回去

正确代码应把 wall 收缩到 w，同时 free energy 下降。

φ(x,0)=−φ₀ tanh[x/(3w)]　→　TDGL　→　−φ₀ tanh(x/w)

2 · 从方程到代码，只看四步

① Grid

1D x 网格；无 disorder、无 thermal noise。

② Laplacian

中心差分 ∂²φ/∂x²。

③ TDGL

显式 Euler 更新 γ∇²φ+αφ−δφ³。

④ Boundaries

左右固定为 +φ₀ / −φ₀，保证存在单墙。

真正的动力学核心
lap = (phi[2:] - 2*phi[1:-1] + phi[:-2]) / dx**2
rhs = (gamma*lap + alpha*phi[1:-1] - delta*phi[1:-1]**3) / eta
phi[1:-1] += dt * rhs
phi[0], phi[-1] = +phi0, -phi0
这四行以后会原样迁移你的建模思维。 alpha*phi-delta*phi**3 来自 -V'(phi)；将来 sliding-FE periodic potential、RF、RB 也应该从 free energy 一项项取 derivative，而不是凭感觉往 update 里塞 force。

3 · Hard gate 怎么写？

设 α=δ=γ=η=1，则 φ₀=1、wexact=√2=1.414214。数值结果用两个独立量验：

profile RMSE = √⟨(φnum−φexact)²⟩　；　wnum=|φ₀/φ′(0)|
不是肉眼验收，而是程序自己 fail
assert rmse < 5e-4
assert width_error < 5e-3

5 · 和你的 sliding-FE 项目怎么接？

本课对象你的项目对应下一步
φ⁴ potentialperiodic stacking / polarization effective potential换成 sliding-specific landscape
clean single wallsingle-wall initialization / E=0 relaxation做真正的 wall-stability certificate
wall widthgrid-resolution sanity确认 dx 能 resolve wall，避免假 depinning
TDGL updatephase-field time evolution再加 constant E、quenched RF/RB、thermal noise
hard regression testsolver 改动后的最低验收gold test 过了才跑 threshold campaign
方法流的真正含义：成熟方法不是“直接算 β”。它先证明 clean object 是对的，再证明 estimator 是对的，再增加 disorder 和 drive，最后才谈 criticality。
