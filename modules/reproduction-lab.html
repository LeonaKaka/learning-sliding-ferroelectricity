0 · 这节到底复现论文的哪一块？

Caballero 的体场层面使用非守恒标量 order parameter（序参量） φ(r,t)、双井 φ⁴ 势和 overdamped Langevin（过阻尼朗之万）/ Model A（A 型模型）动力学；无序为零时，stationary soliton（定态孤子）给出一堵解析可知的畴壁。项目权威来源是 Drive 中的 Caballero et al. 2020 PDF；期刊版本：PRB 102, 104204。

V(φ)=−αφ²/2+δφ⁴/4　；　η∂tφ=γ∇²φ−V′(φ)+h+ξ
φ*(x)=−φ₀ tanh(x/w),　φ₀=√(α/δ),　w=√(2γ/α)本课只取 h=0、T=0、无序为零的一维验证单元。
不是“复现论文图 1”。这是从同一模型和解析结果抽出的最小验证单元。它先检查离散化、边界条件和 TDGL 更新；roughness（粗糙度）/ structure factor（结构因子）后面再复现。

1 · 为什么故意从一堵错误的畴壁开始？

不能直接初始化答案

如果一开始就填解析 tanh，代码“不动”并不能证明积分器正确。

故意设成 3w

初始畴壁比平衡畴壁宽三倍，强迫 TDGL 真正发生弛豫。

看它自己回去

正确代码应把畴壁收缩到 w，同时自由能下降。

φ(x,0)=−φ₀ tanh[x/(3w)]　→　TDGL　→　−φ₀ tanh(x/w)

2 · 从方程到代码，只看四步

① 网格

一维 x 网格；无序为零、无热噪声。

② Laplacian（拉普拉斯算子）

中心差分 ∂²φ/∂x²。

③ TDGL

显式 Euler（欧拉）更新 γ∇²φ+αφ−δφ³。

④ 边界条件

左右固定为 +φ₀ / −φ₀，保证存在单墙。

真正的动力学核心
lap = (phi[2:] - 2*phi[1:-1] + phi[:-2]) / dx**2
rhs = (gamma*lap + alpha*phi[1:-1] - delta*phi[1:-1]**3) / eta
phi[1:-1] += dt * rhs
phi[0], phi[-1] = +phi0, -phi0
这四行以后会原样迁移你的建模思维。 alpha*phi-delta*phi**3 来自 -V'(phi)；将来 sliding ferroelectricity（滑移铁电）的周期势、RF、RB 也应该从自由能一项项求导，而不是凭感觉往更新式里塞力。

3 · 硬性验收条件怎么写？

设 α=δ=γ=η=1，则 φ₀=1、wexact=√2=1.414214。数值结果用两个独立量验证：

剖面 RMSE = √⟨(φnum−φexact)²⟩　；　wnum=|φ₀/φ′(0)|
不是肉眼验收，而是程序自己报错
assert rmse < 5e-4
assert width_error < 5e-3

5 · 和你的滑移铁电项目怎么接？

本课对象你的项目对应下一步
φ⁴ 势周期堆垛 / 极化有效势换成滑移铁电特定能量景观
无序为零的单畴壁单畴壁初始化 / E=0 弛豫做真正的畴壁稳定性验证
畴壁宽度网格分辨率合理性检查确认 dx 能分辨畴壁，避免伪退钉扎
TDGL 更新phase-field（相场）时间演化再加恒定 E、淬火 RF/RB、热噪声
硬性回归测试求解器改动后的最低验收已知答案测试通过后才跑阈值批量扫描
方法流的真正含义：成熟方法不是“直接算 β”。它先证明无序为零时的对象是对的，再证明估计量是对的，再增加无序和驱动，最后才谈临界性。
