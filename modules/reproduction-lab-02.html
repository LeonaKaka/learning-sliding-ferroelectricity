Learning Sliding Ferroelectricity / Reproduction Lab / Lesson 02

二维场里那条“墙”，到底怎么变成一条可测的 u(y)？

Lesson 01 只证明 1D TDGL 能回到正确的 tanh kink。现在进入 Caballero 2020 真正关键的 model-reduction 步骤：先跑 2D Ginzburg–Landau field，再从每一条 y-column 里提取 φ=0 crossing，把 diffuse wall 压成单值 interface u(y)，最后验证 clean flat wall 应满足 B(r)≈0。

这节的核心不是“画出一条黑线”。只有当每个 y 都恰好有一个 crossing、横截面仍符合 tanh、u(y) 真的变平、B(r) 真的降到接近 0，这个 wall extractor 才算通过。

0 · 这次开始真的和论文 Figure 并排比

这次比较到什么程度？ 我们已经复现了 Caballero Fig.1 的方法结构：bulk φ(x,y) → wall crossing → u(y) → transverse tanh profile。因为我们的 T、运行时间和初态与论文 Fig.1 不同，所以现在仍不叫“Fig.1 数值像素级复现”。Lesson 03/04 才会开始对论文的 roughness / structure-factor 曲线做定量 thumbnail reproduction。

1 · 为什么先从一条故意弯的墙开始？

如果直接初始化一个完全平的 wall，最终得到 B(r)=0 并不稀奇——你的 y-Laplacian 写错了也可能“看起来没事”。所以这里先人为加一个长波正弦位移：

u(y,0)=1.5 sin(2πy/Ly)
φ(x,y,0)=−tanh[(x−u(y,0))/w]

clean T=0、h=0 下，gradient energy 会惩罚弯曲。正确的二维 TDGL 应该让这条墙逐步变平，而不是凭边界条件把它瞬间钉死。

检查 x 方向

每个横截面的 wall profile 仍应接近解析 tanh。

检查 y 方向

sinusoidal u(y) 应因 line tension 衰减。

检查整体

free energy 应单调下降，而不是靠 extractor “伪造”平墙。

2 · 从 diffuse field 提取 u(y)

对每个固定 yj 的 column，寻找唯一一对相邻格点满足：

φ(xi,yj) ≥ 0，　φ(xi+1,yj) < 0

再做一次线性插值：

u(yj) = xi − φi,j Δx / [φi+1,j−φi,j]
Extractor 的真正 hard gate
ids = np.where((col[:-1] >= 0.0) & (col[1:] < 0.0))[0]
if len(ids) != 1:
    raise RuntimeError("expected exactly one wall crossing")

i = ids[0]
u[j] = x[i] - col[i] * dx / (col[i+1] - col[i])
这一句 len(ids) != 1 很重要。 如果出现 bubble、overhang 或多重 crossing，就不应该继续默默算一个 u(y)。这正是网站前面一直强调的 topology gate：elastic-line observable 只有在 single-valued mapping 成立时才合法。

3 · 为什么 flat wall 的 B(r) 是另一个独立验收？

B(r)=⟨[u(y+r)−u(y)]²⟩y

如果最终 wall 真正变成平直单墙，那么所有 y 上的 u 都应该近似相同，因此 B(r) 应趋近 0。这里不是拟合 ζ，也不是追求 power law；它只是检验“wall extraction + y 方向动力学”是否自洽。

Lesson 01 验的是 solver 的横向 wall profile；Lesson 02 新增的是 wall geometry estimator。 两节通过以后，我们才有资格在 Lesson 03 给它加 thermal noise，再去看真实的 roughness growth。

5 · 代码里新增了什么？

① 2D Laplacian

x 用固定边界，y 用 periodic boundary。

② Wavy initial wall

让 line tension 有真实工作要做。

③ Zero crossing

把 diffuse φ(x,y) 压成 u(y)。

④ B(r)

从几何线计算最基础 roughness observable。

二维 TDGL 核心
lap_x = (phi[2:] - 2*phi[1:-1] + phi[:-2]) / dx**2
lap_y = (roll_y(+1) - 2*phi[1:-1] + roll_y(-1)) / dy**2

rhs = (gamma*(lap_x + lap_y)
       + alpha*phi[1:-1]
       - delta*phi[1:-1]**3) / eta

phi[1:-1] += dt * rhs
