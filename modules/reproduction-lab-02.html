二维场里那条“墙”，到底怎么变成一条可测的 u(y)？

第 01 课只证明一维 TDGL 能回到正确的 tanh kink（双曲正切扭结）。现在进入 Caballero 2020 真正关键的 model reduction（模型约化）步骤：先跑二维 Ginzburg–Landau（GL）场，再从每一条 y 列中提取 φ=0 零点交叉，把 diffuse wall（弥散畴壁）压成单值界面 u(y)，最后验证无序为零的平直畴壁应满足 B(r)≈0。

这节的核心不是“画出一条黑线”。只有当每个 y 都恰好有一个零点交叉、横截面仍符合 tanh、u(y) 真的变平、B(r) 真的降到接近 0，这个畴壁提取器才算通过。

0 · 这次开始真的和论文 Figure 并排比

这次比较到什么程度？ 我们已经复现了 Caballero Fig.1 的方法结构：体场 φ(x,y) → 畴壁零点交叉 → u(y) → 横向 tanh 剖面。因为我们的 T、运行时间和初态与论文 Fig.1 不同，所以现在仍不叫“Fig.1 数值像素级复现”。第 03/04 课才会开始对论文的 roughness（粗糙度）/ structure factor（结构因子）曲线做定量缩略复现。

1 · 为什么先从一条故意弯的墙开始？

如果直接初始化一堵完全平直的畴壁，最终得到 B(r)=0 并不稀奇——你的 y 方向 Laplacian（拉普拉斯算子）写错了也可能“看起来没事”。所以这里先人为加一个长波正弦位移：

u(y,0)=1.5 sin(2πy/Ly)
φ(x,y,0)=−tanh[(x−u(y,0))/w]

在无序为零且 T=0、h=0 时，gradient energy（梯度能）会惩罚弯曲。正确的二维 TDGL 应该让这堵畴壁逐步变平，而不是凭边界条件把它瞬间钉死。

检查 x 方向

每个横截面的畴壁剖面仍应接近解析 tanh。

检查 y 方向

正弦 u(y) 应因 line tension（线张力）衰减。

检查整体

自由能应单调下降，而不是靠畴壁提取器“伪造”平墙。

2 · 从弥散场提取 u(y)

对每个固定 yj 这一列中，寻找唯一一对相邻格点满足：

φ(xi,yj) ≥ 0，　φ(xi+1,yj) < 0

再做一次线性插值：

u(yj) = xi − φi,j Δx / [φi+1,j−φi,j]
畴壁提取器的真正硬性验收条件
ids = np.where((col[:-1] >= 0.0) & (col[1:] < 0.0))[0]
if len(ids) != 1:
    raise RuntimeError("expected exactly one wall crossing")

i = ids[0]
u[j] = x[i] - col[i] * dx / (col[i+1] - col[i])
这一句 len(ids) != 1 很重要。 如果出现 bubble（气泡畴）、overhang（悬垂）或多重零点交叉，就不应该继续默默计算一个 u(y)。这正是网站前面一直强调的 topology gate（拓扑判据）：elastic line（弹性线）可观测量只有在 single-valued mapping（单值映射）成立时才合法。

3 · 为什么平直畴壁的 B(r) 是另一个独立验收？

B(r)=⟨[u(y+r)−u(y)]²⟩y

如果最终畴壁真正变成平直单墙，那么所有 y 上的 u 都应该近似相同，因此 B(r) 应趋近 0。这里不是拟合 ζ，也不是追求幂律；它只是检验“畴壁提取 + y 方向动力学”是否自洽。

第 01 课验证的是求解器的横向畴壁剖面；第 02 课新增的是畴壁几何估计量。 两节通过以后，我们才有资格在 第 03 课给它加热噪声，再去看真实的粗糙度增长。

5 · 代码里新增了什么？

① 二维 Laplacian（拉普拉斯算子）

x 用固定边界，y 用 periodic boundary（周期边界）。

② 起伏初始畴壁

让线张力真正参与弛豫。

③ 零点交叉

把弥散 φ(x,y) 压成 u(y)。

④ B(r)

从几何线计算最基础的粗糙度可观测量。

二维 TDGL 核心
lap_x = (phi[2:] - 2*phi[1:-1] + phi[:-2]) / dx**2
lap_y = (roll_y(+1) - 2*phi[1:-1] + roll_y(-1)) / dy**2

rhs = (gamma*(lap_x + lap_y)
       + alpha*phi[1:-1]
       - delta*phi[1:-1]**3) / eta

phi[1:-1] += dt * rhs
