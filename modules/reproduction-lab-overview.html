Learning Sliding Ferroelectricity / Reproduction Lab

不是“算出一条曲线”，而是逐层获得结论资格

这 12 课不是从简单代码一路堆到复杂代码。真正的顺序是：先证明对象与离散化没有写错，再证明阈值和可观测量真的测对，最后才问有限尺寸、拟合区间与温度证据是否足以授权普适指数。某一关“不通过”不是坏结果；它是在告诉你下一份算力应该花在哪里。

贯穿 12 课的规则：已知答案测试通过 ≠ 目标物理结论通过；单样本结果 ≠ 热力学极限；一条漂亮幂律 ≠ 普适指数。
代码正确

解析解、归一化、离散化或合成数据能否给出预先知道的答案？

估计量正确

界面位置、阈值、稳态速度、粗糙度和结构因子是否按独立判据稳定？

结论授权

尺寸区间、拟合区间、样本统计与温度区间是否已经足够支撑最终 claim？

Stage A · L01–L05
先证明对象、投影和归一化是对的

这一段不追 β、ζ、ν。目标是建立以后所有临界分析都要依赖的“地基”：墙是什么、怎样从体场提取界面、GL 与 EW 怎样对应、连续白噪声怎样离散。

L01 · TDGL 畴壁已知答案测试解析解

故意从错误宽度出发，让 TDGL 自己收敛到解析 tanh kink；用 RMSE、墙宽和自由能下降验求解器。

通过后才允许相信“无序为零时，代码里的墙是对的”。
L02 · 2D 体场 → 1D 界面可观测量

从二维 φ(x,y) 提取 u(y)，把“看见一条墙”变成可计算的界面坐标。

先验证提取规则，再谈粗糙度或运动学。
L03 · EW 粗糙化基准方程基准

在干净的 EW 问题上检查粗糙度分析与论文 Eq.19 对照，先把界面统计工具校准。

这里验证分析链，不把有限时间斜率自动当作渐近指数。
L04 · GL → EW 映射边界模型映射

低温下检查体场与弹性线的映射，同时主动寻找高温下映射何时失效。

低温映射通过；高温 breakdown 被检测到，不能把失效润色成成功。
L05 · 随机键投影与白噪声归一化无序归一化

把体场随机键投影成短程相关钉扎力，并用解析 correlator 检查连续白噪声的离散尺度。

投影与归一化通过；这还没有证明任何退钉扎普适指数。
Stage B · L06–L08
再证明“你测的量”有资格进入临界分析

L06 开始面对有无序的真实几何，L07–L08 则把阈值与稳态速度拆成独立测量问题。这里最重要的纪律是：有限样本判据先稳定，才把数据交给指数拟合。

L06 · 含无序 GL / EW 几何对照B(r), S(q)

比较两种模型的粗糙度与结构因子，区分“跨模型几何一致”与“渐近 ζ 已闭合”。

几何映射通过；渐近 ζ 判据未通过。
L07 · 单样本退钉扎阈值搜索fc bracket

先分类 pinned / moving，再用二分夹逼最后钉扎点与第一个运动态；解析粒子模型做已知答案测试。

只授权有限样本阈值区间；不授权热力学 fc。
L08 · 稳态速度 v(f)速度估计量

剔除退钉扎瞬态，检查 dt 收敛，并用解析运动态验证速度估计量。

稳态速度估计量通过；本课明确不拟合 β。
Stage C · L09–L12
最后才挑战临界指数与有限温闭合

这一阶段允许出现“代码测试通过，但物理结论不授权”。判断标准从“能不能算”升级为“拟合区间、尺寸区间与温度区间是否稳定到足以支持普适 claim”。

L09 · β 拟合区间稳定性β

逐步缩小 Δf 拟合区间，看有效 β 是否形成稳定平台，并把阈值不确定性与样本波动分开。

回归已知答案测试通过；β 拟合区间判据未通过，普适 β 不授权。
L10 · 超粗糙 ζζ

同时读局域与全局粗糙度，识别 super-rough（超粗糙）几何，并检查有限尺寸是否足以闭合 ζ。

超粗糙特征可见；热力学 ζ 尚未闭合。
L11 · 有限尺寸标度与 νν / FSS

先用合成数据验证有限尺寸标度分析，再检查真实尺寸区间中的 ν 是否稳定。

合成 ν 已知答案测试通过；尺寸区间稳定性未通过，普适 ν 不授权。
L12 · 热圆整与蠕变边界ψ / creep

从 Brownian 热噪声归一化开始，再测试热指数分析与低温蠕变渐近区是否真正解析。

噪声与合成热指数测试通过；热圆整区间未闭合，ψ 与 creep-law / μ 均不授权。
两条路线不要混在一起：侧栏的 Paper1（L01–L06）/ Paper2（L07–L12）告诉你这些课属于哪条论文方法线；本页的 Stage A/B/C 告诉你每一步在证据资格上处于哪里。论文线可以换，证据纪律不能换。
