# Pinning, Creep & Roughness — frozen lesson assets

Authoritative sources are the project Google Drive PDFs. Final lesson policy:

- Source passages are rendered as selectable HTML text, not screenshots.
- PDF line wraps/hyphenation may be normalized only to restore reading order; wording is not rewritten inside source blocks.
- Figures are rendered from the authoritative PDFs at 600 DPI, cropped to the complete intended figure/panels, visually inspected, and frozen as lossless PNG.
- GitHub Pages only validates and deploys frozen local assets; it does not download papers, crop figures, or recompress images.

Frozen figures:

- `tybell2002-fig3-creep.png` — Tybell et al. 2002, Fig. 3, wall speed vs inverse field / creep law.
- `paruch2005-fig3-roughness.png` — Paruch et al. 2005, Fig. 3(a,b), B(L) scaling / roughness exponent. Final crop QA: 2150×920 lossless PNG; neighboring page text removed while preserving both panels, axes, labels, legend, and ζ values.
- `kim2014-fig1-pinning.png` — Kim et al. 2014, Fig. 1(a–c), switched-area plateau and PFM pinning/de-pinning sequences.
