# Switching Pathways static evidence assets

Authoritative sources are the project Google Drive PDFs. This module follows the same frozen-asset standard as Foundations.

## Rendering / text policy

- Source quotations are HTML text transcribed from the Drive PDFs; only PDF ligatures and line-wrap hyphenation are normalized. Wording/order are not rewritten.
- Figures are rendered from the exact Drive PDF page at 600 DPI and cropped to the complete figure boundary.
- Final figure files are lossless PNG. No WebP/JPEG down-conversion is used for the lesson assets.
- Each crop is visually checked for panel labels, axes, legends/color bars, arrows, structural labels, and boundary completeness.
- GitHub Pages only validates and deploys static files; it never downloads the papers or generates crops.
