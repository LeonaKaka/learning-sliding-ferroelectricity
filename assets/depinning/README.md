# Depinning lesson assets

Authoritative sources are the PDFs stored inside the project Google Drive folder `sliding ferroelectric/` and its `03 Depinning, elastic-interface, RFIM theory` descendant.

## Frozen evidence policy

- Source passages are rendered as selectable HTML text in `modules/depinning.html`; paragraph screenshots are forbidden.
- Figure assets are rendered from the authoritative PDFs at 600 DPI and cropped to the complete teaching-relevant Figure/panels.
- Final images are lossless PNG. No WebP/JPEG recompression is used for lesson figures.
- Each crop is visually inspected for axes, labels, legends, panel boundaries and neighboring-page contamination before freezing.
- GitHub Pages only validates and deploys the frozen files; it does not download papers or regenerate crops.

## Assets

- `chauve2000-fig1-force-velocity.png` — Chauve, Giamarchi & Le Doussal (2000), Fig. 1: creep / depinning / flow regimes.
