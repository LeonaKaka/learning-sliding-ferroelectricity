## Frozen evidence policy

- Source passages are selectable HTML text in `modules/depinning.html`; paragraph screenshots are forbidden.
- Figure assets are lossless PNG crops derived from the corresponding source PDFs; no WebP/JPEG recompression is used.
- Crops were visually inspected for axes, labels, legends, panel boundaries and neighboring-page contamination.
- The updated lesson was rendered at 1365 px desktop and 412 px mobile widths with no horizontal overflow; figures and source blocks remained readable.
- GitHub Pages only validates and deploys frozen files; it never downloads papers or generates/crops figures.
